## AI Model APIs

AI Model APIs are the unified entry point for callers, grouped by request protocol into OpenAI, Claude, and Gemini families, plus a rerank endpoint. See the [AI model APIs overview](/nookmux/api/ai-model/index) for authentication and shared conventions.
