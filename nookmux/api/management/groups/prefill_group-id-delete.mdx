Delete a prefill group by ID.

Requires **Admin** permissions. See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/prefill_group/3' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### Path parameters

<ParamField path="id" type="integer" required>
  ID of the prefill group to delete.
</ParamField>

## Response

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": null
}
```

</ResponseExample>

### Response fields

<ResponseField name="success" type="boolean" required>
  Whether the group was deleted.
</ResponseField>

<ResponseField name="message" type="string" required>
  Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data" type="null" required>
  Always `null`; the endpoint returns no payload.
</ResponseField>

<Note>
Management endpoints return HTTP `200` even on business failures; always check the `success` field. Deletion is a soft delete: the record is kept with a deletion timestamp and no longer appears in list results, so its name can be reused when creating a new group. Deleting an ID that does not exist also succeeds and affects no rows.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Invalid parameters | `id` is not a valid integer |
| Database error, please try again later | Deleting the group failed; see server logs |
