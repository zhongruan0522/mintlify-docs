---
title: Get Home Page Content
description: Fetch the custom home page content configured in console content settings.
api: "GET /api/home_page_content"
---

Returns the custom home page content configured by the administrator in console content settings. The value is returned as a raw string and rendering is handled by the frontend. Returns an empty string when no content is configured, in which case the frontend falls back to its default home page.

This endpoint is public and requires no authentication. See [Authentication](/nookmux/api/management/auth) for details on how management API requests are authenticated.

## Request

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/home_page_content'
```

</RequestExample>

## Response

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": "<h1>Welcome to NookMux</h1><p>...</p>"
}
```

</ResponseExample>

### Response fields

<ResponseField name="success" type="boolean" required>
  Whether the request succeeded.
</ResponseField>

<ResponseField name="message" type="string" required>
  Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data" type="string" required>
  The custom home page content configured in console content settings, as a raw string. Empty string when no content is set.
</ResponseField>
