---
title: Get System Status
description: "Fetch the public bootstrap configuration the frontend needs before login: branding, login options, dashboard panel switches and console content."
api: "GET /api/status"
---

Returns the public configuration used to render the pre-login shell and initialize the frontend: branding, available login options, Turnstile settings, dashboard panel switches, passkey parameters and optional console content (API info, announcements, FAQ). The response is identical for anonymous and authenticated callers; administrator-only configuration (sidebar module layout, build version) is deliberately not included and is served by dedicated admin endpoints.

This endpoint is public and requires no authentication. See [Authentication](/nookmux/api/management/auth) for details on how management API requests are authenticated.

## Request

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/status'
```

</RequestExample>
