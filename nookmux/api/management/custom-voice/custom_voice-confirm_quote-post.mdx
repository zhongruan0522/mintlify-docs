---
title: Get Custom Voice Confirm Quote
description: Query the quota a custom voice confirmation would charge, without charging.
api: "POST /api/custom_voice/confirm_quote"
---

Returns the quota amount that confirming the given custom voice would charge. Only pending `preview` records created by the current user can be quoted. No quota is deducted and the voice state does not change.

The amount is derived from the billing model configured for the custom voice feature: the model price (charged once per confirmation) when set, otherwise the model ratio priced as 1000 tokens, multiplied by the group ratio of the configured custom voice group (dynamic ratio included when configured). Missing or zero pricing fails closed instead of returning a free quote.

Requires **User** permissions (any logged-in account). See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/custom_voice/confirm_quote' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "voice_id": "my-custom-voice-01"
}'
```

</RequestExample>

### Body

<ParamField path="body.voice_id" type="string" required>
  Voice ID of the pending preview record previously created through the preview endpoint.
</ParamField>

## Response

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": {
    "voice_id": "my-custom-voice-01",
    "quota_cost": 50000
  }
}
```

</ResponseExample>

### Response fields

<ResponseField name="success" type="boolean" required>
  Whether the quote was computed.
</ResponseField>

<ResponseField name="message" type="string" required>
  Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data" type="object" required>
  The quote result.

  <Expandable title="data structure">
    <ResponseField name="voice_id" type="string" required>
      The quoted voice ID.
    </ResponseField>
    <ResponseField name="quota_cost" type="integer" required>
      Quota (in wallet quota units) that confirming this voice would charge.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
Management endpoints return HTTP `200` even on business failures; always check the `success` field. A malformed JSON body is instead rejected with HTTP `400`. Preview records older than 7 days are cleaned up before the lookup and can no longer be quoted.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Invalid parameters (HTTP 400) | The JSON body is missing or malformed |
| Voice ID cannot be empty | `voice_id` is empty after trimming |
| Custom voice feature is disabled, please contact the administrator | The custom voice feature switch is off |
| Billing model is not configured, please contact the administrator | The custom voice billing model ID is empty |
| Voice validation failed, please try again later | The expired-preview cleanup failed |
| Invalid voice ID | No record exists for `voice_id` |
| This voice does not need confirmation or has already been processed | The record is not in the `preview` state |
| No permission to operate this voice | The record belongs to another user |
| The selected billing model is currently unavailable, please contact the administrator | No pricing exists for the billing model (fail closed, never free) |
| The price of the selected billing model is invalid, please contact the administrator | The computed quota is not positive |
