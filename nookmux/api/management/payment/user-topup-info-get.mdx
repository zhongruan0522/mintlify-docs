---
title: Get Top-up Information
description: Console top-up page configuration - enabled payment methods, minimum amounts, preset options and discounts.
api: "GET /api/user/topup/info"
---

Returns everything the console top-up page needs to render: the enabled payment methods, whether online (Epay) and Stripe top-ups are available, the minimum top-up amounts, preset amount options and discounts, and the external manual top-up link.

Requires **User** permissions (any logged-in account). See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/user/topup/info' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## Response

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": {
    "enable_online_topup": true,
    "enable_stripe_topup": true,
    "pay_methods": [
      { "name": "支付宝", "color": "rgba(var(--semi-blue-5), 1)", "type": "alipay" },
      { "name": "微信", "color": "rgba(var(--semi-green-5), 1)", "type": "wxpay" },
      { "name": "Stripe", "type": "stripe", "color": "rgba(var(--semi-purple-5), 1)", "min_topup": "1" }
    ],
    "min_topup": 1,

}
```

</ResponseExample>

### Response fields

<ResponseField name="success" type="boolean" required>
Whether the top-up configuration was returned.
</ResponseField>

<ResponseField name="message" type="string" required>
Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data.enable_online_topup" type="boolean" required>
Whether Epay online top-up is available: the gateway address, merchant ID and key are all configured.
</ResponseField>

<ResponseField name="data.enable_stripe_topup" type="boolean" required>
Whether Stripe top-up is available: the Stripe API key, webhook secret and price ID are all configured.
</ResponseField>

<ResponseField name="data.pay_methods" type="array" required>
Payment methods configured by the administrator, plus a `stripe` entry automatically appended when Stripe is enabled and not already present in the configured list.

<Expandable title="pay_methods entry structure">
  <ParamField path="name" type="string" required>
    Display name of the payment method.
  </ParamField>
  <ParamField path="type" type="string" required>
    Channel type, used as `payment_method` when initiating a payment.
  </ParamField>
  <ParamField path="color" type="string">
    Display color of the payment method badge.
  </ParamField>
  <ParamField path="min_topup" type="string">
    Minimum top-up amount enforced for this method, when configured.
  </ParamField>
</Expandable>
</ResponseField>

<ResponseField name="data.min_topup" type="integer" required>
Minimum top-up quantity for Epay online top-ups.
</ResponseField>

<ResponseField name="data.stripe_min_topup" type="integer" required>
Minimum top-up quantity for Stripe top-ups.
</ResponseField>

<ResponseField name="data.amount_options" type="array" required>
Preset top-up quantities offered on the top-up page, as integers.
</ResponseField>

<ResponseField name="data.discount" type="object" required>
Preset discount per top-up quantity: keys are quantities (serialized as strings) and values are multipliers, for example `{"100": 0.9}` for a 10% discount at quantity 100. Empty object when no discounts are configured.
</ResponseField>

<ResponseField name="data.topup_link" type="string" required>
External link shown for manual top-up; empty when not configured.
</ResponseField>
