---
title: Delete Model
description: Delete a model metadata entry by ID (soft delete).
api: "DELETE /api/models/{id}"
---

Delete a model metadata entry. The record is soft-deleted: it disappears from all model metadata queries, and the deletion is recorded in the audit log. After a successful deletion the pricing cache is refreshed.

Requires **Admin** permissions. See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/models/43' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### Path parameters

<ParamField path="id" type="integer" required>
Model metadata record ID.
</ParamField>

## Response

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": null
}
```

</ResponseExample>

### Response fields

<ResponseField name="success" type="boolean" required>
Whether the entry was deleted.
</ResponseField>

<ResponseField name="message" type="string" required>
Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data" type="null" required>
Always `null`; the endpoint returns no data.
</ResponseField>

<Note>
Management endpoints return HTTP `200` even on business failures; always check the `success` field.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Invalid parameters | `id` is not an integer |
| Database error | The deletion failed; see server logs |
