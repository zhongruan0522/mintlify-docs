---
title: Get Specific Model
description: Retrieve a single model metadata entry by ID with its enriched binding information.
api: "GET /api/models/{id}"
---

Retrieve one model metadata record by ID. The returned entry is enriched with binding information: the enabled channels serving the model, the user groups allowed to use it, its billing modes, its supported endpoint types, and for rule-based entries the concrete model names matched by the rule.

Requires **Admin** permissions. See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/models/42' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### Path parameters

<ParamField path="id" type="integer" required>
Model metadata record ID.
</ParamField>

### Response fields

<ResponseField name="success" type="boolean" required>
Whether the query was executed.
</ResponseField>

<ResponseField name="message" type="string" required>
Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data" type="object" required>
Model metadata entry with binding information. The field structure is identical to [Get All Model Metadata](/nookmux/api/management/model-management/models-get).
</ResponseField>

<Note>
Management endpoints return HTTP `200` even on business failures; always check the `success` field.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Invalid parameters | `id` is not an integer |
| Database error | No record with this ID exists, or the query failed |
