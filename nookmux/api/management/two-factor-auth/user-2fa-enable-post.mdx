---
title: Enable 2FA
description: Confirm a TOTP code to activate the pending two-factor-authentication setup for the logged-in account.
api: "POST /api/user/2fa/enable"
---

Activates the pending 2FA record created by [Set Up 2FA](/nookmux/api/management/two-factor-auth/user-2fa-setup-post). The request must carry the current 6-digit TOTP code generated by the authenticator app for the secret returned during setup. On success the 2FA record is marked enabled, and subsequent logins of this account require a TOTP code or a backup code.

Requires **User** permission (any logged-in user). See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/user/2fa/enable' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "code": "123456"
}'
```

</RequestExample>

### Body

<ParamField path="body.code" type="string" required>
Current 6-digit TOTP code from the authenticator app. Spaces are ignored. Backup codes are not accepted by this endpoint.
</ParamField>

## Response

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Two-factor authentication enabled successfully",
  "data": null
}
```

</ResponseExample>

### Response fields

<ResponseField name="success" type="boolean" required>
Whether 2FA was enabled.
</ResponseField>

<ResponseField name="message" type="string" required>
Localized success message; error description when `success` is `false`.
</ResponseField>

<ResponseField name="data" type="null" required>
Always `null`; this endpoint returns no data payload.
</ResponseField>

<Note>
The code is verified directly against the stored secret; a wrong code here is not counted toward the verification lockout that applies to disabling, backup-code regeneration, and login verification.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Invalid request body | The JSON body is missing, `code` is empty, or the code is not 6 digits |
| Setup not completed | No pending 2FA record exists; call `POST /api/user/2fa/setup` first |
| 2FA already enabled | 2FA is already active for this account |
| Verification code invalid | The TOTP code does not match the stored secret |
| Database error | Loading or updating the 2FA record failed; see server logs |
