---
title: Create Token
description: Create a new API token for the current user; the full key is returned exactly once in the response.
api: "POST /api/token/"
---

Create a new API token owned by the current user. The token key is generated server-side (site key prefix, `sk-` by default, plus 48 random characters) and returned exactly once in the response. Each user can hold at most 1000 tokens.

Requires a logged-in user (**User** permissions). See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/token/' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "my-token",
  "expired_time": -1,
  "quota_type": 1,
  "remain_quota": 500000,
  "unlimited_quota": false,
  "group": "default",
  "cross_group_retry": false,
  "model_limits_enabled": false,
  "model_limits": "",
  "model_mapping": null,
  "allow_ips": null
}'
```

</RequestExample>

### Body

<ParamField path="body.name" type="string" required>
  Display name of the token, at most 50 characters.
</ParamField>

<ParamField path="body.expired_time" type="integer" default="-1">
  Unix timestamp (seconds) when the token expires. `-1` means never expires.
</ParamField>

<ParamField path="body.quota_type" type="integer" default="0">
  Quota mode:

  - `0`: unlimited quota (forces `unlimited_quota` to `true`).
  - `1`: permanent quota (`remain_quota` is spent and never refilled).
  - `2`: time-window quota (`window_hours` / `window_quota` / `window_start_hour`).
  - `3`: time-window plus cycle quota (window fields plus `cycle_days` / `cycle_quota`).

  For legacy compatibility, `0` combined with `unlimited_quota: false` is treated as `1`. Any other value is rejected.
</ParamField>

<ParamField path="body.unlimited_quota" type="boolean">
  Whether the token has unlimited quota. Overridden by the server according to `quota_type`: forced to `true` for `0`, `false` for `1`-`3`.
</ParamField>

<ParamField path="body.remain_quota" type="integer">
  Total quota of a permanent-quota token. Required to be `0` or positive and no greater than the server-side upper bound (1,000,000,000 quota units, i.e. 5 × 10^14 at the default 500,000 quota per unit). Only validated for `quota_type` `1`.
</ParamField>

<ParamField path="body.window_hours" type="integer">
  Length of each quota window in hours, at least `1`. Effective for `quota_type` `2` and `3`.
</ParamField>

<ParamField path="body.window_quota" type="integer">
  Quota granted per window, must be greater than `0`. Effective for `quota_type` `2` and `3`.
</ParamField>

<ParamField path="body.window_start_hour" type="integer" default="0">
  Hour of day (`0`-`23`) the window grid is aligned to. Effective for `quota_type` `2` and `3`.
</ParamField>

<ParamField path="body.cycle_days" type="integer">
  Length of each quota cycle in days, at least `1`. Effective for `quota_type` `3`.
</ParamField>

<ParamField path="body.cycle_quota" type="integer">
  Quota granted per cycle, must be greater than `0`. Effective for `quota_type` `3`.
</ParamField>

<ParamField path="body.model_limits_enabled" type="boolean" default="false">
  Whether `model_limits` is enforced for this token.
</ParamField>

<ParamField path="body.model_limits" type="string">
  Comma-separated list of model names the token may call.
</ParamField>

<ParamField path="body.model_mapping" type="string">
  JSON object of token-level model redirects, for example `{"gpt-4o": "gpt-4o-2024-08-06"}`. Keys and values must be non-empty strings of at most 256 characters that do not contain `:`, `/`, tab, carriage return, line feed or spaces; the whole value is limited to 64 KB. `null` or an empty string leaves the redirect unconfigured.
</ParamField>

<ParamField path="body.allow_ips" type="string">
  Newline-separated IP whitelist for the token key. `null` or empty means no restriction.
</ParamField>

<ParamField path="body.group" type="string">
  Group used for channel selection. Empty means the token follows the user's group; the special value `auto` enables automatic group ordering.
</ParamField>

<ParamField path="body.cross_group_retry" type="boolean">
  Whether retry may cross to the next group. Only effective when `group` is `auto`.
</ParamField>

<ParamField path="body.id / body.key / body.status / body.created_time / body.accessed_time / body.used_quota" type="any">
  Server-managed fields. Values in the request body are ignored: `key` is generated by the server, `user_id` is taken from the authenticated user, `status` starts as enabled (`1`), and the usage counters start at `0`.
</ParamField>

## Response

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": {
    "key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
  }
}
```

</ResponseExample>

### Response fields

<ResponseField name="success" type="boolean" required>
  Whether the token was created.
</ResponseField>

<ResponseField name="message" type="string" required>
  Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data.key" type="string" required>
  The full token key (site key prefix, `sk-` by default, plus 48 random characters). Returned only here; list and detail endpoints always return a masked key.
</ResponseField>

<Note>
Management endpoints return HTTP `200` even on business failures; always check the `success` field.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Invalid request body | The JSON body is missing or malformed |
| Token name too long | `name` exceeds 50 characters |
| Invalid model mapping | `model_mapping` is not a JSON object of non-empty string keys and values, contains characters that cannot be carried (`:` `/` whitespace), a name exceeds 256 characters, or the value exceeds 64 KB |
| Quota value cannot be negative | `quota_type` is `1` but `remain_quota` is negative |
| Quota value exceeds valid range | `remain_quota` exceeds the server-side upper bound |
| Window duration must be at least 1 hour | `quota_type` is `2` or `3` but `window_hours` is below `1` |
| Window quota must be greater than 0 | `quota_type` is `2` or `3` but `window_quota` is not positive |
| Window start hour must be between 0 and 23 | `window_start_hour` is outside `0`-`23` |
| Cycle days must be at least 1 | `quota_type` is `3` but `cycle_days` is below `1` |
| Cycle total quota must be greater than 0 | `quota_type` is `3` but `cycle_quota` is not positive |
| Invalid quota type | `quota_type` is not one of `0`, `1`, `2`, `3` (after legacy compatibility) |
| Maximum token limit reached | The user already holds 1000 tokens |
| Failed to generate token | Generating the random key failed |
| Database error | Persisting the token failed; see server logs |
