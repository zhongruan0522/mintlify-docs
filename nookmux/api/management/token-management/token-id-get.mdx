---
title: Get Specified Token
description: Retrieve a single token owned by the current user by its id, with the key masked.
api: "GET /api/token/{id}"
---

Retrieve a single token by its id. Only tokens owned by the current user can be accessed; the `key` is masked in the response.

Requires a logged-in user (**User** permissions). See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/token/3' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### Path parameters

<ParamField path="id" type="integer" required>
  Token id.
</ParamField>

### Response fields

<ResponseField name="success" type="boolean" required>
  Whether the request succeeded.
</ResponseField>

<ResponseField name="message" type="string" required>
  Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data" type="object" required>
  The token object. Same structure as the items in [Get All Tokens](/nookmux/api/management/token-management/token-get); the `key` is masked with asterisks of the same length as the real key.
</ResponseField>

<Note>
Management endpoints return HTTP `200` even on business failures; always check the `success` field.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Invalid parameters | `id` is not an integer |
| Database error | No token with this id belongs to the current user, or the query failed; see server logs |
