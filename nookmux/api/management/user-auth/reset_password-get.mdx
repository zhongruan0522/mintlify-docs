---
title: Send Password Reset Email
description: Request a password reset email containing a single-use reset link valid for 10 minutes.
api: "GET /api/reset_password"
---

Sends a password reset email to the specified address. When the address belongs to a registered account, the email contains a single-use link of the form `{server_address}/user/reset?email={email}&token={token}` that is valid for 10 minutes; the actual password change is performed by `POST /api/user/reset`. To prevent account enumeration, this endpoint always returns the same success response whether or not the address is registered, and the email is delivered asynchronously after the response has been sent.

This endpoint is **Public** — no authentication is required. See [Authentication](/nookmux/api/management/auth) for how management API requests are authenticated.

<Note>
This endpoint applies a stricter per-IP rate limit (CriticalRateLimit); exceeding it returns HTTP `429`. When Cloudflare Turnstile verification is enabled on the server, a valid `turnstile` token must be supplied (unless the current session has already passed the check).
</Note>

## Request

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/reset_password?email=user%40example.com&turnstile=XXXX.DUMMY.TOKEN.XXXX'
```

</RequestExample>

### Query parameters

<ParamField path="email" type="string" required>
Email address of the account to reset. Must be a syntactically valid email address.
</ParamField>

<ParamField path="turnstile" type="string">
Cloudflare Turnstile token. Required only when Turnstile verification is enabled on the server and the current session has not already passed the check.
</ParamField>

## Response

<ResponseExample>

```json 200
{
  "success": true,
  "message": "If the account exists, a password reset email has been sent. Please check your inbox",
  "data": null
}
```

</ResponseExample>

### Response fields

<ResponseField name="success" type="boolean" required>
Whether the request was accepted. Always `true` for a syntactically valid `email`, regardless of account existence.
</ResponseField>

<ResponseField name="message" type="string" required>
Localized confirmation message. The exact wording depends on the request language.
</ResponseField>

<ResponseField name="data" type="null" required>
Always `null` for this endpoint.
</ResponseField>

<Note>
To avoid leaking which addresses are registered, the response is identical for known and unknown addresses, and delivery failures are only recorded in server logs.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Invalid parameters | `email` is missing or not a valid email address |
