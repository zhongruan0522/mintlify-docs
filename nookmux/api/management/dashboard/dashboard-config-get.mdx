---
title: Get dashboard config
description: Retrieve the current dashboard configuration as a flat key-value map.
api: "GET /api/dashboard/config"
---

Retrieves the current dashboard configuration. `data` is a flat map of configuration keys to their current values; every value is returned as a string, with booleans encoded as `true`/`false` and numbers as decimal strings.

Requires **Admin** permissions. See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/dashboard/config' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### Response fields

<ResponseField name="success" type="boolean" required>
Whether the configuration was returned.
</ResponseField>

<ResponseField name="message" type="string" required>
Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data" type="object">
  Flat map of every dashboard configuration key to its current value as a string. `default` values below are the built-in defaults shown when nothing has been changed.

  <Expandable title="data structure">
    <ResponseField name="api_info_enabled" type="string" required>
      Whether the API info panel is enabled (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="announcements_enabled" type="string" required>
      Whether the announcements panel is enabled (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="default_time_range_days" type="string" required>
      Default dashboard query time range in days. Default `7`.
    </ResponseField>
    <ResponseField name="faq_enabled" type="string" required>
      Whether the FAQ panel is enabled (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="max_time_range_days" type="string" required>
      Maximum dashboard query time range in days, 1-365. Default `31`.
    </ResponseField>
    <ResponseField name="media_convert_stats_enabled" type="string" required>
      Whether the image/video-to-URL statistics panel is enabled (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="quota_data_enabled" type="string" required>
      Whether the quota data (time series) panel is enabled (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="quota_data_refresh_interval" type="string" required>
      Quota data refresh interval in seconds, 60-86400. Default `3600`.
    </ResponseField>
    <ResponseField name="quota_data_track_by_model" type="string" required>
      Whether quota data is aggregated by model (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="quota_data_track_by_user" type="string" required>
      Whether quota data is aggregated by user (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="quota_data_track_tokens" type="string" required>
      Whether token usage is recorded with quota data (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="rankings_enabled" type="string" required>
      Whether the rankings panel is enabled (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="rankings_model_limit" type="string" required>
      Number of models kept in the rankings, 1-100. Default `20`.
    </ResponseField>
    <ResponseField name="rankings_platform_limit" type="string" required>
      Number of client platforms (agents) kept in the rankings, 1-50. Default `10`.
    </ResponseField>
    <ResponseField name="rankings_refresh_interval" type="string" required>
      Rankings refresh interval in seconds, 60-86400. Default `300`.
    </ResponseField>
    <ResponseField name="rankings_vendor_limit" type="string" required>
      Number of vendors kept in the rankings, 1-50. Default `5`.
    </ResponseField>
    <ResponseField name="uptime_kuma_enabled" type="string" required>
      Whether the Uptime Kuma panel is enabled (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="uptime_kuma_refresh_interval" type="string" required>
      Uptime Kuma refresh interval in seconds, 30-3600. Default `60`.
    </ResponseField>
    <ResponseField name="user_analytics_enabled" type="string" required>
      Whether the user analytics (user ranking and trend) panel is enabled (`true`/`false`). Default `true`.
    </ResponseField>
    <ResponseField name="user_analytics_refresh_interval" type="string" required>
      User analytics refresh interval in seconds, 60-86400. Default `3600`.
    </ResponseField>
    <ResponseField name="user_analytics_top_n" type="string" required>
      Number of users kept in the user analytics ranking, 1-100. Default `20`.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
[Update dashboard config](/nookmux/api/management/dashboard/dashboard-config-put) accepts the same keys with native JSON types (booleans, integers); this endpoint returns them stringified.
</Note>

## Error messages

| Condition | Description |
| --- | --- |
| Serialization failed | Converting the configuration to a map failed; `message` is `Failed to get configuration: {error}`, see server logs |
