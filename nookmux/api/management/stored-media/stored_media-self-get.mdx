---
title: Get Current User Stored Media
description: Paginated list of the stored images and videos belonging to the current user.
api: "GET /api/stored_media/self"
---

Returns the stored media records of the user making the request, newest first. These records are the images and videos NookMux keeps for the multimodal auto-URL conversion feature; the binary payload itself is never returned, only its metadata and a short-lived download URL.

Requires **User** permission (any logged-in user). See [Authentication](/nookmux/api/management/auth) for how to authenticate management API requests.

## Request

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/stored_media/self?p=1&page_size=10' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 2'
```

</RequestExample>

### Query parameters

<ParamField path="p" type="integer" default="1">
Page number, starting at 1.
</ParamField>

<ParamField path="page_size" type="integer" default="10">
Page size, capped at 100. The legacy aliases `ps` and `size` are also accepted when `page_size` is absent.
</ParamField>

<ParamField path="start_timestamp" type="integer">
Lower bound on `created_at` as a Unix timestamp in seconds. Omit or pass `0` for no lower bound.
</ParamField>

<ParamField path="end_timestamp" type="integer">
Upper bound on `created_at` as a Unix timestamp in seconds. Omit or pass `0` for no upper bound.
</ParamField>

### Response fields

<ResponseField name="success" type="boolean" required>
Whether the records were loaded.
</ResponseField>

<ResponseField name="message" type="string" required>
Error description when `success` is `false`; empty otherwise.
</ResponseField>

<ResponseField name="data" type="object" required>
Pagination envelope.

<Expandable title="data structure">
  <ParamField path="page" type="integer" required>
    Current page number.
  </ParamField>
  <ParamField path="page_size" type="integer" required>
    Page size actually applied (after defaulting and the 100 cap).
  </ParamField>
  <ParamField path="total" type="integer" required>
    Total number of matching records.
  </ParamField>
  <ParamField path="items" type="array" required>
    Stored media records of the current page, ordered by `created_at` descending, then `id` descending.
  </ParamField>
</Expandable>
</ResponseField>

<ResponseField name="data.items[]" type="object" required>
One stored media record.

<Expandable title="stored media structure">
  <ParamField path="id" type="string" required>
    Record ID (UUID) of the stored media.
  </ParamField>
  <ParamField path="media_type" type="string" required>
    Media type: `image` or `video`.
  </ParamField>
  <ParamField path="created_at" type="integer" required>
    Storage time as a Unix timestamp in seconds.
  </ParamField>
  <ParamField path="mime_type" type="string" required>
    MIME type of the original file, for example `image/png` or `video/mp4`.
  </ParamField>
  <ParamField path="size_bytes" type="integer" required>
    Size of the stored file in bytes.
  </ParamField>
  <ParamField path="url" type="string" required>
    Signed download URL for the media content, in the form `{server_address}/mcp/{media_type}/{id}?exp=...&sig=...`. The signature expires after one hour.
  </ParamField>
</Expandable>
</ResponseField>

## Error messages

| Condition | Description |
| --- | --- |
| Database error, please try again later | Loading the records failed; see server logs |
