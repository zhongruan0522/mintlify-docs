<Warning>
  The Fine-tuning endpoints are not implemented. The routes are kept for forward compatibility, but every call returns `501 Not Implemented` and nothing is forwarded to any upstream channel.
</Warning>

Affected endpoints:

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/v1/fine-tunes` | Create a fine-tune job |
| `GET` | `/v1/fine-tunes` | List fine-tune jobs |
| `GET` | `/v1/fine-tunes/{fine_tune_id}` | Retrieve a fine-tune job |
| `POST` | `/v1/fine-tunes/{fine_tune_id}/cancel` | Cancel a fine-tune job |
| `GET` | `/v1/fine-tunes/{fine_tune_id}/events` | List fine-tune events |

## Response

```json 501
{
  "error": {
    "message": "API not implemented",
    "type": "nookmux_error",
    "param": "",
    "code": "api_not_implemented"
  }
}
```
