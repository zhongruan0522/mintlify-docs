---
title: Redemption Codes
description: Create, edit, enable, disable, and delete redemption codes with quotas, quantities, and expiration, which users redeem on the Wallet page.
---

The `/redemption-codes` page is used by administrators to create, edit, enable, disable, and delete redemption codes.

Common uses:

- Generate codes for top-ups or quota gifts.
- Set code quota, quantity, expiration, and status.
- Batch-manage codes.

Regular users can enter redemption codes in **Wallet** to redeem quota.
