title: API Keys
---

The API keys page is available at `/keys`. It is used to create, view, edit, reset, and delete user API keys.

Common capabilities:

- Set key name, quota, expiration time, and enabled state.
- Choose available groups and models.
- Configure request routing strategies such as the `auto` group and cross-group retries.
- Perform batch operations and copy API configuration.

## Key Format

An API key is the site key prefix followed by a 48-character random string. The prefix defaults to `sk-` and can be customized by administrators under **System Settings → Site & Branding → System Information**. The **API Keys** page displays and copies the complete key, so it can be used directly in applications.

Administrators can use the **Group prices** tab of **System Settings → Billing & Payments → Pricing Settings** to configure user-selectable groups, the auto group, and group ratios.
