---
title: API Keys
---

The API keys page is available at `/keys`. It is used to create, view, edit, reset, and delete user API keys.

Common capabilities:

- Set key name, quota, expiration time, and enabled state.
- Choose available groups and models.
- Configure call strategies such as `auto` groups and cross-group retries.
- Batch operations and copy call settings.

## Key Format

An API key is the site key prefix followed by a 48-character random string. The prefix defaults to `sk-` and can be customized by admins under System Settings → Site & Branding → System Information. The "Keys" page shows and copies the complete key, so it can be used directly in applications.

Administrators can use **System Settings → Billing & Payments → Group Pricing** to configure available groups, auto groups, and group ratios.
