description: View top-up, payment, and order processing records from the Wallet page or directly, and use usage logs and audit logs to troubleshoot crediting and order status.
---

The `/order-query` route is used to view top-up, payment, and order processing records.

Users can access it from **Wallet** or directly. Administrators can use usage logs and audit logs to troubleshoot payment crediting and order status changes.
