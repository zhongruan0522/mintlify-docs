The old "Other Settings" page now mainly corresponds to **System Settings → Site & Branding**.

## System Information

Configurable items include:

- System name `SystemName`
- Server address `ServerAddress`
- Docs link `general_setting.docs_link`
- Key prefix `general_setting.token_key_prefix`
- Logo URL
- Footer text
- About page content
- Home page content
- Terms of Service and Privacy Policy

The key prefix is used when creating API keys. It defaults to `sk-`, can be up to 16 characters, and must end with `-`. It only applies to newly created keys; existing keys created before a custom prefix was set are automatically migrated at startup to add the `sk-` prefix.

Home and About content support Markdown and HTML. If a URL is entered, it is loaded in an iframe.

## Top Navigation

You can control whether entries such as Home, Console, Key Lookup, Pricing, Leaderboard, Docs, and About are shown. Pricing and Leaderboard can also require login.

## Sidebar Modules

You can control whether console sidebar modules are shown, including entries under Experience Center, General, Personal, Support, and Admin. At the top of the page, a standalone "Default Collapse Sidebar" switch controls whether the sidebar is collapsed by default for new users; toggling it saves immediately.

Related implementation: `web/src/features/system-settings/site/section-registry.tsx`, `web/src/features/system-settings/maintenance/config.ts`.
