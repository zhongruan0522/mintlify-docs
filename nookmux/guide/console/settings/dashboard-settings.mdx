---
title: Console Content
---

The old "Data Dashboard Settings" page now lives under **System Settings → Console Content**.

Configurable sections:

- **Dashboard Configuration**: the single source for data dashboard behavior — data metric switches (quota data, user analytics, rankings, media conversion stats), write-layer aggregation granularity, panel switches, four refresh intervals (quota data / user analytics / rankings / Uptime Kuma, in seconds), and data limits (default and maximum query time range, ranking model/vendor counts, user analytics Top N). It absorbs the former Data Dashboard section (data export toggle, refresh interval in minutes, default time granularity).
- **Announcements**: console announcements.
- **API Address**: quick API information shown on the home page and in the console.
- **FAQ**: common questions.
- **Uptime Kuma**: monitoring status page groups.
- **Usage Log Fields**: fields visible in log details for administrators and regular users.

These settings affect console presentation and dashboard data aggregation; they do not directly change relay behavior.
