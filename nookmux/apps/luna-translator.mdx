<Info>
  LunaTranslator is an open-source and free visual novel (GalGame) translator that supports HOOK text extraction, OCR, offline translation, and large-model translation. It can connect to OpenAI-compatible services through the "General Large Model Interface".
</Info>

- GitHub Repository: [https://github.com/HIllya51/LunaTranslator](https://github.com/HIllya51/LunaTranslator)
- Project Documentation: [Download & FAQ](https://docs.lunatranslator.org/en/README.html)
- Large Model Translation Interface: [https://docs.lunatranslator.org/en/guochandamoxing.html](https://docs.lunatranslator.org/en/guochandamoxing.html)

## Supported Features

- **HOOK**: Extracts game text and works with almost all common and niche visual novels.
- **In-game Translation**: Some games can display translations directly in the game for a more immersive experience.
- **OCR**: Built-in offline OCR, plus support for multiple online OCR engines.
- **Large Model Translation**: Supports OpenAI-compatible interfaces as a translation engine.
- **Language Learning**: Japanese word segmentation, furigana, AnkiConnect, and Yomitan.
- **Speech Synthesis / Speech Recognition**: Supports many online and offline options.

## Installation

Download and install it from the [LunaTranslator documentation - Download & FAQ](https://docs.lunatranslator.org/en/README.html).

## Connect to NookMux in LunaTranslator

LunaTranslator's "General Large Model Interface" uses the OpenAI-compatible protocol and can point directly to NookMux.

### Configuration Steps

1. Create a token on the NookMux console's "Keys" page and copy the API Key (it starts with the site key prefix, default `sk-`).
2. Open LunaTranslator → **Settings** → **Translation Settings**. In the large model interface area, click the "+" button above the list and choose the "General Large Model Interface", then name the new interface in the pop-up window.
3. Activate the copied interface, click its settings button, and fill in:

   | Item | Value |
   | --- | --- |
   | API endpoint | NookMux site address + `/v1`, for example `https://your-domain.com/v1`; the app requests `<address>/chat/completions` automatically |
   | API Key | NookMux token |
   | Model | Click the refresh button next to the `Model` dropdown to fetch the model list, or enter the model name manually |

4. Click "OK" to save.

Turn on the switch next to the interface to enable it. For more usage details, see the official LunaTranslator documentation: [Large Model Translation Interface](https://docs.lunatranslator.org/en/guochandamoxing.html).
