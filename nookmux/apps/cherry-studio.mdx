## Integration

Cherry Studio ships with a built-in New API provider. One address covers the OpenAI Chat, OpenAI Responses, Anthropic Messages, and Gemini protocols, all of which NookMux supports.

### Parameters

| Item | Value |
| --- | --- |
| Provider | New API (built in), or a custom provider |
| API Key | NookMux token (starts with the site key prefix, default `sk-`), created and copied from the "Keys" page |
| API Host | `https://your-domain.com`, the site root. Cherry Studio completes the version and path for each protocol (such as `/v1` or `/v1beta`), so do not paste a full path like `/chat/completions` |
| Models | Click "Sync models" and pick the ones you want, or add them by hand |

### Configuration Steps

1. Create a token on the NookMux console's "Keys" page and copy the API key.
2. Open Cherry Studio's **Settings**, go to **Model Service**, and enable **New API** in the provider list. You can also add a custom provider from the add-provider button.
3. Paste the NookMux token into **API Key** and set **API Host** to `https://your-domain.com`.
4. Click **Model Check** to confirm connectivity, then click **Sync models** to fetch and enable the models you want. When you add a model by hand, the model ID must match the model name configured in the NookMux channel.
5. Go back to the chat page and start a conversation with the new model.

## Image Generation

If your channel includes image generation models such as DALL·E or Gemini image models, select the model on the **Painting** page and set it as the default under **Settings** → **Default Models** → **Painting Model**. With a custom provider, also fill in "Image Generation Base URL" under the provider's endpoint settings.

## Additional Features

Knowledge base and smart assistant features use the same provider setup and can all point to the same NookMux provider. For more details, see the [Cherry Studio official documentation](https://cherryai.com/docs/en).
