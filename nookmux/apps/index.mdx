## Integration Guide

Most apps only need the following to connect to NookMux:

1. **API Address**: Your NookMux service address. The three compatible interfaces have different base addresses, and each app appends paths in its own way, so follow the individual app page for the exact value: the OpenAI-compatible interface is `https://your-domain.com/v1`; the full Claude-compatible address is `https://your-domain.com/v1/messages` (Claude Code's `ANTHROPIC_BASE_URL`, for example, takes only the site root); the Gemini-compatible interface is `https://your-domain.com/v1beta`.
2. **API Key**: The token created on the NookMux console's "Keys" page, starting with the site key prefix (default `sk-`; admins can customize it under "System Settings" → "Site & Branding" → "System Information").
3. **Model Name**: Choose a model that has been configured in the channel.

For detailed setup steps, see the individual app pages.
