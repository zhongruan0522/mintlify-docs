## Integration

AstrBot connects to NookMux through the OpenAI-compatible Chat Completions interface.

### Configuration Steps

#### Get a NookMux API Key

After registering and logging in to NookMux, open the console's "Keys" page, create a token, and copy the generated API Key (it starts with the site key prefix, default `sk-`).

#### Add a Model Provider in AstrBot

1. Open the AstrBot admin panel, go to the "Chat Completion" tab of the model providers page, and click "Add".
2. Choose `OpenAI Compatible` from the template list.
3. Fill in the provider name, "API Key" (the NookMux token), and "Base URL" (called API Base URL in the official docs):
   - AstrBot and NookMux on the same machine, neither in a container: `http://localhost:3000/v1`
   - Online deployment: `https://your-domain.com/v1`

   When AstrBot runs in Docker, `localhost` points to the container itself, so use the host address instead: `http://host.docker.internal:3000/v1` on Docker Desktop (Mac / Windows), or `http://<docker0 gateway IP>:3000/v1` on Linux (`172.17.0.1` by default). See the official [Docker deployment docs](https://docs.astrbot.app/deploy/astrbot/docker.html).

4. Click "Save and Fetch Models", find the model you want in the available models list, click `+` next to it, and make sure the model is enabled. If the model list cannot be fetched, click "Save Configuration" first, then click "Custom Model" and enter the model ID manually. Use "Test Model" next to a model to check connectivity.

#### Set the Chat Model

Go to "Config", select the config to use, set "Chat Model" under "AI" → "Model" to the model you just added, and click "Save Configuration" in the bottom-right corner.

AstrBot will then call the AI models configured in NookMux.
