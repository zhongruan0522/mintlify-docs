## Core Features

- **Multi-Session Chat**: Independent contexts for each session, with conversation data stored locally.
- **Multi-Model Support**: Supports OpenAI, Claude, Gemini, Qwen, and other mainstream models, plus local models such as Ollama and LM Studio.
- **Multi-Agent Mode**: Run multiple AI agents at the same time and manage them through MCP.
- **File Management**: File tree browsing, drag-and-drop uploads, and AI-assisted organization.
- **Preview Panel**: Previews PDF, Office, code, Markdown, images, and other formats, with live editing support.
- **Multi-Channel Access**: WebUI remote access, Telegram integration, and Feishu integration.

## Integration

AionUi connects to NookMux through an OpenAI-compatible interface.

### Parameters

| Item | Value |
| --- | --- |
| Model platform | New API (or "Custom") |
| API endpoint | `https://your-domain.com/v1` (include `/v1`; AionUi appends `/chat/completions` to it) |
| API Key | NookMux token (starts with the site key prefix, default `sk-`), created and copied from the "Keys" page |
| Model name | The model ID configured in the NookMux channel |
| Request protocol | OpenAI (shown only for the New API platform) |

### Configuration Steps

1. **Open the model settings**: Go to "Settings" → "Models" and click "Add Model".
2. **Choose the model platform**: Select "New API" (or "Custom").
3. **Fill in the API information**: Enter `https://your-domain.com/v1` as the API endpoint, paste the NookMux token as the API Key, and leave "Full URL" turned off.
4. **Add a model**: Click the search icon next to the model name field to fetch the model list, or enter model names directly (multiple are allowed).
5. **Request protocol**: With the New API platform, set the request protocol to "OpenAI". Model names starting with `claude` or `gemini` are auto-detected as other protocols, so change them back manually.
6. **Start using**: After saving, click the health check icon on the model row to confirm connectivity. Custom models are currently available only to the Aion CLI agent; other agents use their own built-in models.
