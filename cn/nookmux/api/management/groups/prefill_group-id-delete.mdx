---
title: 删除预填分组
description: 按 ID 删除一个预填分组。
api: "DELETE /api/prefill_group/{id}"
---

按 ID 删除一个预填分组。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/prefill_group/3' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  要删除的预填分组 ID。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": null
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  分组是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="null" required>
  恒为 `null`；该接口不返回任何数据体。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。删除为软删除：记录保留删除时间戳并不再出现在列表结果中，因此其名称可在新建分组时重新使用。删除不存在的 ID 同样返回成功，且不会影响任何记录。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| Invalid parameters | `id` 不是合法整数 |
| Database error, please try again later | 删除分组失败，详见服务端日志 |
