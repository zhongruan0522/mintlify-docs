---
title: 创建预填分组
description: 创建一个可复用的预填分组。
api: "POST /api/prefill_group/"
---

创建一个预填分组。`name` 必须非空且在未删除分组内唯一，`type` 必须非空。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/prefill_group/' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "name": "gpt-flagship",
  "type": "model",
  "items": ["gpt-4o", "gpt-4o-mini"],
  "description": "Flagship OpenAI models"
}'
```

</RequestExample>

### 请求体

<ParamField path="body.name" type="string" required>
  分组名，在未删除分组内唯一，最长 64 字符。用于在控制台下拉框中展示。
</ParamField>

<ParamField path="body.type" type="string" required>
  分组类别，例如 `model`、`tag` 或 `endpoint`。服务端仅要求该字段非空。
</ParamField>

<ParamField path="body.items" type="array">
  保存分组取值的字符串 JSON 数组，例如模型名列表。省略时存为 `null`。
</ParamField>

<ParamField path="body.description" type="string">
  自由备注，最长 255 字符。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": {
    "id": 3,
    "name": "gpt-flagship",
    "type": "model",
    "items": ["gpt-4o", "gpt-4o-mini"],
    "description": "Flagship OpenAI models",
    "created_time": 1735776000,
    "updated_time": 1735776000
  }
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  分组是否创建成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
  创建成功的预填分组。`id`、`created_time`、`updated_time` 由服务端填充；其余字段为请求内容落库后的表示。

  <Expandable title="prefill group 结构">
    <ResponseField name="id" type="integer" required>
      服务端分配的分组 ID。
    </ResponseField>
    <ResponseField name="name" type="string" required>
      未删除分组内唯一的分组名，最长 64 字符。
    </ResponseField>
    <ResponseField name="type" type="string" required>
      分组类别，例如 `model`、`tag` 或 `endpoint`。
    </ResponseField>
    <ResponseField name="items" type="array" required>
      保存分组取值的字符串 JSON 数组；请求省略 `items` 时为 `null`。
    </ResponseField>
    <ResponseField name="description" type="string">
      自由备注；为空时省略。
    </ResponseField>
    <ResponseField name="created_time" type="integer" required>
      创建时间，Unix 时间戳（秒），由服务端写入。
    </ResponseField>
    <ResponseField name="updated_time" type="integer" required>
      创建时等于 `created_time`。
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。服务端维护字段（`id`、`created_time`、`updated_time`）可在请求中省略。名称唯一性仅针对未删除的分组：分组被删除后，其名称可再次使用。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| Invalid request body | JSON 请求体缺失或格式错误 |
| Group name and type cannot be empty | `name` 或 `type` 缺失或为空 |
| Group name already exists | 已存在同名且未删除的分组 |
| Database error, please try again later | 分组落库失败，详见服务端日志 |
