---
title: 获取仪表板配置
description: 以扁平键值对形式获取当前仪表板配置。
api: "GET /api/dashboard/config"
---

获取当前仪表板配置。`data` 为配置键到当前值的扁平映射；所有值均以字符串返回，布尔值为 `true`/`false`，数值为十进制字符串。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/dashboard/config' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
是否成功返回配置。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object">
  全部仪表板配置键到当前值（字符串）的扁平映射。下方 `default` 为未做任何修改时的内置默认值。

  <Expandable title="data 结构">
    <ResponseField name="api_info_enabled" type="string" required>
      是否启用 API 信息面板（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="announcements_enabled" type="string" required>
      是否启用公告面板（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="default_time_range_days" type="string" required>
      仪表板默认查询时间范围（天）。默认 `7`。
    </ResponseField>
    <ResponseField name="faq_enabled" type="string" required>
      是否启用 FAQ 面板（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="max_time_range_days" type="string" required>
      仪表板最大查询时间范围（天），1-365。默认 `31`。
    </ResponseField>
    <ResponseField name="media_convert_stats_enabled" type="string" required>
      是否启用图片/视频转 URL 统计面板（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="quota_data_enabled" type="string" required>
      是否启用配额数据（时间序列）面板（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="quota_data_refresh_interval" type="string" required>
      配额数据刷新间隔（秒），60-86400。默认 `3600`。
    </ResponseField>
    <ResponseField name="quota_data_track_by_model" type="string" required>
      是否按模型维度聚合配额数据（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="quota_data_track_by_user" type="string" required>
      是否按用户维度聚合配额数据（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="quota_data_track_tokens" type="string" required>
      是否随配额数据记录 token 用量（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="rankings_enabled" type="string" required>
      是否启用排行榜面板（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="rankings_model_limit" type="string" required>
      排行榜保留的模型数量，1-100。默认 `20`。
    </ResponseField>
    <ResponseField name="rankings_refresh_interval" type="string" required>
      排行榜刷新间隔（秒），60-86400。默认 `300`。
    </ResponseField>
    <ResponseField name="rankings_vendor_limit" type="string" required>
      排行榜保留的供应商数量，1-50。默认 `5`。
    </ResponseField>
    <ResponseField name="uptime_kuma_enabled" type="string" required>
      是否启用 Uptime Kuma 面板（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="uptime_kuma_refresh_interval" type="string" required>
      Uptime Kuma 刷新间隔（秒），30-3600。默认 `60`。
    </ResponseField>
    <ResponseField name="user_analytics_enabled" type="string" required>
      是否启用用户分析（用户排行/趋势）面板（`true`/`false`）。默认 `true`。
    </ResponseField>
    <ResponseField name="user_analytics_refresh_interval" type="string" required>
      用户分析刷新间隔（秒），60-86400。默认 `3600`。
    </ResponseField>
    <ResponseField name="user_analytics_top_n" type="string" required>
      用户排行保留的用户数量，1-100。默认 `20`。
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
[更新仪表板配置](/cn/nookmux/api/management/dashboard/dashboard-config-put)接受相同键的原生 JSON 类型（布尔值、整数）；本接口将其以字符串形式返回。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 序列化失败 | 配置转换为映射失败，`message` 为 `获取配置失败: {错误详情}`，详见服务端日志 |
