---
title: 获取令牌密钥
description: 获取当前用户名下指定令牌的完整密钥；列表与详情接口仅返回脱敏密钥。
api: "POST /api/token/{id}/key"
---

获取单个令牌的完整密钥（站点密钥前缀，默认 `sk-`，加 48 位随机串）。列表与详情接口返回的密钥均为脱敏星号，本接口返回完整密钥。只能访问当前用户自己名下的令牌。

需要登录（**User** 权限）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

<Note>
  本接口挂载了更严格的限流（CriticalRateLimit）。
</Note>

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/token/3/key' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  令牌 id。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": {
    "key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
  }
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  是否成功返回密钥。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data.key" type="string" required>
  令牌完整密钥（站点密钥前缀，默认 `sk-`，加 48 位随机串）。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 参数非法 | `id` 不是整数 |
| 数据库错误 | 当前用户名下不存在该 id 的令牌，或查询失败；详见服务端日志 |
