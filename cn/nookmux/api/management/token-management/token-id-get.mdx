---
title: 获取指定令牌
description: 按 id 获取当前用户名下的单个令牌，密钥脱敏返回。
api: "GET /api/token/{id}"
---

按 id 获取单个令牌。只能访问当前用户自己名下的令牌；响应中的 `key` 已脱敏。

需要登录（**User** 权限）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/token/3' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  令牌 id。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
  请求是否成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
  令牌对象。结构与[获取所有令牌](/cn/nookmux/api/management/token-management/token-get)中的 items 元素一致；`key` 脱敏为与真实密钥等长的星号。
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 参数非法 | `id` 不是整数 |
| 数据库错误 | 当前用户名下不存在该 id 的令牌，或查询失败；详见服务端日志 |
