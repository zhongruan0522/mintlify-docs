---
title: 删除令牌
description: 按 id 删除当前用户名下的令牌。
api: "DELETE /api/token/{id}"
---

按 id 删除单个令牌。只能删除当前用户自己名下的令牌；删除数据库记录的同时会清理令牌缓存。

需要登录（**User** 权限）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/token/3' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  令牌 id。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": ""
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  令牌是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。该接口成功时不返回 `data` 字段。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 数据库错误 | `id` 缺失或非法、当前用户名下不存在该 id 的令牌，或删除失败；详见服务端日志 |
