---
title: 批量删除令牌
description: 一次调用删除当前用户名下的多个令牌，并返回实际删除数量。
api: "POST /api/token/batch"
---

在单个事务中删除当前用户名下的多个令牌。不存在或属于其他用户的 id 会被静默跳过且不计数；响应返回实际删除的令牌数量。

需要登录（**User** 权限）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/token/batch' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "ids": [1, 2, 3]
}'
```

</RequestExample>

### 请求体

<ParamField path="body.ids" type="integer[]" required>
  待删除令牌的 id 列表。必须为非空数组；仅匹配当前用户名下的令牌。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": 2
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  批量删除是否成功完成。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="integer" required>
  实际删除的令牌数量。未在当前用户令牌中命中的 id 不计入。
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 参数非法 | JSON 请求体格式错误或 `ids` 为空 |
| 数据库错误 | 批量删除失败，详见服务端日志 |
