---
title: 获取当前用户存储媒体
description: 分页列出当前用户的多模态自动转 URL 存储图片与视频。
api: "GET /api/stored_media/self"
---

分页返回当前登录用户的存储媒体记录，按时间倒序排列。这些记录是 NookMux 为多模态自动转 URL 功能保存的图片与视频；接口只返回元数据与临时下载链接，不返回二进制内容。

需要**用户**权限（任意登录用户）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/stored_media/self?p=1&page_size=10' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 2'
```

</RequestExample>

### 查询参数

<ParamField path="p" type="integer" default="1">
页码，从 1 开始。
</ParamField>

<ParamField path="page_size" type="integer" default="10">
页大小，上限 100。未传 `page_size` 时兼容旧别名 `ps` 与 `size`。
</ParamField>

<ParamField path="start_timestamp" type="integer">
`created_at` 的下界，Unix 秒级时间戳。省略或传 `0` 表示不限下界。
</ParamField>

<ParamField path="end_timestamp" type="integer">
`created_at` 的上界，Unix 秒级时间戳。省略或传 `0` 表示不限上界。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": {
    "page": 1,
    "page_size": 10,

        "created_at": 1790110000,
        "mime_type": "image/png",

      }
    ]
  }

```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
记录是否加载成功。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
分页结构。

<Expandable title="data 结构">
  <ParamField path="page" type="integer" required>
    当前页码。
  </ParamField>
  <ParamField path="page_size" type="integer" required>
    实际生效的页大小（经过默认值填充与 100 上限截断）。
  </ParamField>
  <ParamField path="total" type="integer" required>
    符合条件的记录总数。
  </ParamField>
  <ParamField path="items" type="array" required>
    当前页的存储媒体记录，按 `created_at` 倒序、`id` 倒序排列。
  </ParamField>
</Expandable>
</ResponseField>

<ResponseField name="data.items[]" type="object" required>
单条存储媒体记录。

<Expandable title="存储媒体结构">
  <ParamField path="id" type="string" required>
    存储媒体记录 ID（UUID）。
  </ParamField>
  <ParamField path="media_type" type="string" required>
    媒体类型：`image` 或 `video`。
  </ParamField>
  <ParamField path="created_at" type="integer" required>
    存入时间，Unix 秒级时间戳。
  </ParamField>
  <ParamField path="mime_type" type="string" required>
    原始文件的 MIME 类型，例如 `image/png`、`video/mp4`。
  </ParamField>
  <ParamField path="size_bytes" type="integer" required>
    存储文件大小，单位字节。
  </ParamField>
  <ParamField path="url" type="string" required>
    媒体内容的签名下载链接，格式为 `{server_address}/mcp/{media_type}/{id}?exp=...&sig=...`，签名有效期 1 小时。
  </ParamField>
</Expandable>
</ResponseField>
