---
title: 获取存储媒体详情
description: 返回单个存储图片或视频的元数据及临时签名下载链接。
api: "GET /api/stored_media/{media_type}/{id}"
---

按媒体类型与记录 ID 返回单条存储媒体的元数据，以及媒体内容的签名下载链接。

需要**用户**权限（任意登录用户）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

<Note>
仅记录所有者与管理员可读取。记录实际存储的媒体类型与 `{media_type}` 路径段不一致时，按资源不存在处理。
</Note>

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/stored_media/image/0d8c9f9a-1b2c-3d4e-5f6a-7b8c9d0e1f2a' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 2'
```

</RequestExample>

### 路径参数

<ParamField path="media_type" type="string" required>
记录的媒体类型：`image` 或 `video`。匹配前会去除首尾空白并转为小写。
</ParamField>

<ParamField path="id" type="string" required>
存储媒体记录 ID（UUID），不能为空。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": {
    "id": "0d8c9f9a-1b2c-3d4e-5f6a-7b8c9d0e1f2a",
    "media_type": "image",
    "created_at": 1790110000,
    "mime_type": "image/png",
    "size_bytes": 204800,
    "url": "https://your-nookmux-domain/mcp/image/0d8c9f9a-1b2c-3d4e-5f6a-7b8c9d0e1f2a?exp=1790120000&sig=5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0c"
  }
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
记录是否加载成功。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
存储媒体元数据。

<Expandable title="data 结构">
  <ParamField path="id" type="string" required>
    存储媒体记录 ID（UUID）。
  </ParamField>
  <ParamField path="media_type" type="string" required>
    媒体类型：`image` 或 `video`。
  </ParamField>
  <ParamField path="created_at" type="integer" required>
    存入时间，Unix 秒级时间戳。
  </ParamField>
  <ParamField path="mime_type" type="string" required>
    原始文件的 MIME 类型，例如 `image/png`、`video/mp4`。
  </ParamField>
  <ParamField path="size_bytes" type="integer" required>
    存储文件大小，单位字节。
  </ParamField>
  <ParamField path="url" type="string" required>
    媒体内容的签名下载链接，格式为 `{server_address}/mcp/{media_type}/{id}?exp=...&sig=...`，签名有效期 1 小时。
  </ParamField>
</Expandable>
</ResponseField>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| id 不能为空 | 路径中的 `{id}` 为空或仅空白字符 |
| media_type 必须为 image 或 video | `{media_type}` 不是 `image` 或 `video` |
| 资源不存在 | `{id}` 对应的记录不存在，或其存储类型与 `{media_type}` 不一致 |
| 无权访问该资源 | 调用者既非所有者也非管理员 |
| 数据库错误，请稍后重试 | 记录加载失败，详见服务端日志 |
