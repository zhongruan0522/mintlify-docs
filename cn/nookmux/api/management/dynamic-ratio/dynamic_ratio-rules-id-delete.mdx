---
title: 删除动态倍率规则
description: 按 ID 删除一条动态倍率规则，并立即刷新运行时规则缓存。
api: "DELETE /api/dynamic_ratio/rules/{id}"
---

按 ID 删除一条动态倍率规则。删除成功后运行时规则缓存立即刷新，删除操作会记录到审计日志。

需要**超级管理员**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/dynamic_ratio/rules/3' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
要删除的规则 ID。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": null
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
规则是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="null" required>
恒为 `null`；该接口不返回数据。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。删除已不存在的规则同样返回成功。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 规则 ID 无效 | `message` 为「无效的规则 ID」；`id` 不是整数 |
| 数据库错误 | `message` 为「数据库错误，请稍后重试」；删除失败，详见服务端日志 |
