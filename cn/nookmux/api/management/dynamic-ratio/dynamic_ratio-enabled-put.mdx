---
title: 设置动态倍率开关
description: 写入 DynamicRatioEnabled 配置，全局开启或关闭动态倍率功能。
api: "PUT /api/dynamic_ratio/enabled"
---

通过写入 `DynamicRatioEnabled` 配置来全局开启或关闭动态倍率功能。关闭期间所有规则均被跳过，计费回退到配置的分组倍率；开关状态用户可通过[获取动态倍率状态](/cn/nookmux/api/management/dynamic-ratio/dynamic_ratio-status-get)查看。变更会记录到审计日志。

需要**超级管理员**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://your-nookmux-domain/api/dynamic_ratio/enabled' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "enabled": true
}'
```

</RequestExample>

### 请求体

<ParamField path="body.enabled" type="boolean" required>
是否开启动态倍率。省略该字段等同于传 `false`。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": null
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
开关是否写入成功。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="null" required>
恒为 `null`；该接口不返回数据。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。关闭开关不会删除任何规则，重新开启后规则继续生效。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 请求体非法 | `message` 为「请求体格式不正确」；JSON 缺失或格式错误 |
| 数据库错误 | `message` 为「数据库错误，请稍后重试」；写入配置失败，详见服务端日志 |
