---
title: 发送密码重置邮件
description: 请求发送包含一次性重置链接的密码重置邮件，链接有效期 10 分钟。
api: "GET /api/reset_password"
---

向指定邮箱发送密码重置邮件。若该邮箱属于已注册账号，邮件中会包含一次性链接，格式为 `{server_address}/user/reset?email={email}&token={token}`，10 分钟内有效；实际改密动作由 `POST /api/user/reset` 完成。为防止账号枚举，无论邮箱是否已注册，本接口始终返回相同的成功响应，且邮件在响应返回后异步投递。

本接口为 **Public（公开）**——无需鉴权。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

<Note>
本接口挂载了更严格的按 IP 限流（CriticalRateLimit），超出返回 HTTP `429`。当服务端开启 Cloudflare Turnstile 人机验证时，必须携带有效的 `turnstile` 令牌（当前会话已通过校验的除外）。
</Note>

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/reset_password?email=user%40example.com&turnstile=XXXX.DUMMY.TOKEN.XXXX'
```

</RequestExample>

### 查询参数

<ParamField path="email" type="string" required>
待重置密码的账号邮箱，必须为格式合法的邮箱。
</ParamField>

<ParamField path="turnstile" type="string">
Cloudflare Turnstile 令牌。仅当服务端开启 Turnstile 人机验证且当前会话尚未通过校验时必填。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "若该账户已注册，重置邮件已发送，请检查收件箱",
  "data": null
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
请求是否被接受。只要 `email` 格式合法即为 `true`，与账号是否存在无关。
</ResponseField>

<ResponseField name="message" type="string" required>
本地化的确认提示，具体文案随请求语言变化。
</ResponseField>

<ResponseField name="data" type="null" required>
本接口恒为 `null`。
</ResponseField>

<Note>
为避免泄露哪些邮箱已注册，已注册与未注册邮箱的响应完全一致，投递失败仅记录在服务端日志中。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 参数无效 | `email` 缺失或不是合法邮箱地址 |
