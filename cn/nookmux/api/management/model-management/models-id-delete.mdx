---
title: 删除模型
description: 按 ID 删除模型元数据记录（软删除）。
api: "DELETE /api/models/{id}"
---

删除一条模型元数据记录。记录为软删除：从所有模型元数据查询中消失，并写入审计日志。删除成功后会刷新定价缓存。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/models/43' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
模型元数据记录 ID。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": null
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
记录是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="null" required>
恒为 `null`，本接口不返回数据。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 无效的参数 | `id` 不是整数 |
| 数据库错误 | 删除失败，详见服务端日志 |
