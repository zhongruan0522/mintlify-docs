---
title: 搜索模型
description: 按关键词与供应商筛选搜索模型元数据，支持分页。
api: "GET /api/models/search"
---

按关键词与供应商筛选搜索模型元数据记录，返回一页附带绑定信息的模型记录以及匹配总数。关键词匹配 `model_name` 与 `tags`；供应商筛选既支持供应商 ID，也支持供应商名称片段。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/models/search?keyword=gpt&vendor=1&p=1&page_size=10' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 查询参数

<ParamField path="keyword" type="string">
关键词，对 `model_name` 与 `tags` 做包含匹配。为空时关闭关键词筛选。
</ParamField>

<ParamField path="vendor" type="string">
供应商筛选。整数值按供应商 ID 精确过滤；其他任意值匹配名称包含该字符串的供应商。为空时关闭筛选。
</ParamField>

<ParamField path="p" type="integer" default="1">
页码，从 `1` 开始。
</ParamField>

<ParamField path="page_size" type="integer" default="10">
每页条数，上限 `100`。未传 `page_size` 时也接受旧别名 `ps` 与 `size`。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
搜索是否成功执行。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data.page" type="integer" required>
当前页码。
</ResponseField>

<ResponseField name="data.page_size" type="integer" required>
本次请求实际生效的每页条数。
</ResponseField>

<ResponseField name="data.total" type="integer" required>
匹配筛选条件的记录总数。
</ResponseField>

<ResponseField name="data.items" type="array" required>
当前页的模型元数据记录，按 ID 降序排列，并附带绑定信息。字段结构与[获取所有模型元数据](/cn/nookmux/api/management/model-management/models-get)完全一致。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。
</Note>
