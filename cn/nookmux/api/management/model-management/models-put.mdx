---
title: 更新模型元数据
description: 全量覆盖更新模型元数据记录，或在 status_only 模式下仅更新状态。
api: "PUT /api/models/"
---

更新一条模型元数据记录。默认的全量更新模式会用请求体覆盖全部持久化字段，请求体中省略的字段会被重置为零值。`status_only=true` 时只写入 `status` 字段，可避免其余字段被误清空。更新成功后会刷新定价缓存，并写入审计日志。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://your-nookmux-domain/api/models/' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "id": 43,
  "model_name": "gpt-4o-mini",
  "description": "Affordable and intelligent small model",
  "icon": "openai",
  "tags": "llm,chat",
  "vendor_id": 1,
  "endpoints": "[\"openai\"]",
  "context_length": 128000,
  "max_output_tokens": 16384,
  "input_modalities": ["text", "image"],
  "output_modalities": ["text"],
  "knowledge_cutoff": "2023-10",
  "release_date": "2024-07-18",
  "parameter_count": "unknown",
  "status": 1,
  "name_rule": 0
}'
```

</RequestExample>

### 查询参数

<ParamField path="status_only" type="string" default="">
设为 `true` 时仅更新 `status` 字段，请求体中的其余字段一律忽略。取其他值（或不传该参数）执行全量更新。
</ParamField>

### 请求体

<ParamField path="body.id" type="integer" required>
要更新的模型元数据记录 ID，不得为 `0`。
</ParamField>

<ParamField path="body.model_name" type="string">
模型名。在其他记录中必须保持唯一；仅在全量更新模式下校验。
</ParamField>

<ParamField path="body.description" type="string">
模型的自由描述。
</ParamField>

<ParamField path="body.icon" type="string">
控制台展示的图标标识。
</ParamField>

<ParamField path="body.tags" type="string">
逗号分隔的标签。
</ParamField>

<ParamField path="body.vendor_id" type="integer">
模型所属供应商的 ID；`0` 表示未指定供应商。供应商记录由 [供应商接口](/cn/nookmux/api/management/vendors/vendors-get) 管理。
</ParamField>

<ParamField path="body.endpoints" type="string">
支持的端点类型，序列化为 JSON 数组字符串，例如 `"[\"openai\",\"anthropic\"]"`。可取值：`openai`、`openai-response`、`openai-response-compact`、`anthropic`、`gemini`、`jina-rerank`、`image-generation`、`embeddings`。
</ParamField>

<ParamField path="body.context_length" type="integer" default="0">
上下文窗口大小（token 数）。
</ParamField>

<ParamField path="body.max_output_tokens" type="integer" default="0">
最大输出 token 数。
</ParamField>

<ParamField path="body.input_modalities" type="array of string">
接受的输入模态，例如 `["text","image"]`。
</ParamField>

<ParamField path="body.output_modalities" type="array of string">
输出模态，例如 `["text"]`。
</ParamField>

<ParamField path="body.capabilities" type="array of string">
模型的自由能力标签。
</ParamField>

<ParamField path="body.knowledge_cutoff" type="string">
模型的知识截止日期。
</ParamField>

<ParamField path="body.release_date" type="string">
模型的发布日期。
</ParamField>

<ParamField path="body.parameter_count" type="string">
参数规模描述。
</ParamField>

<ParamField path="body.status" type="integer" default="1">
模型状态：`1` 启用，`0` 停用。`status_only=true` 时仅写入该字段。
</ParamField>

<ParamField path="body.name_rule" type="integer" default="0">
`model_name` 与具体模型的匹配方式：`0` 精确匹配，`1` 前缀匹配，`2` 包含匹配，`3` 后缀匹配。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
更新是否成功应用。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
请求体中模型对象的回显（仅包含请求体携带的字段）。持久化字段即上文所列字段；字段语义见[获取所有模型元数据](/cn/nookmux/api/management/model-management/models-get)。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。全量更新模式下省略的可选字段会被写入零值，因此务必提交完整记录；status_only 模式下只需 `id` 与 `status`。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 请求体非法 | JSON 缺失或格式错误 |
| 缺少模型 ID | `id` 缺失或为 `0` |
| 模型名称已存在 | 其他记录使用了相同的 `model_name`（全量更新模式） |
| 数据库错误 | 加载原记录（`id` 不存在也会落到这里）或保存更新失败 |
