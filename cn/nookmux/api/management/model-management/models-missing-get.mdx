---
title: 获取缺失模型
description: 列出已被启用渠道服务但尚无模型元数据记录的模型名。
api: "GET /api/models/missing"
---

列出已被至少一个启用渠道服务、但在模型元数据表中没有对应记录的模型名。可用于发现仍需配置元数据的模型，或作为[同步上游模型](/cn/nookmux/api/management/model-management/models-sync_upstream-post)的输入。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/models/missing' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "data": [
    "claude-opus-4-6",
    "gemini-2.5-pro"
  ]
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
查询是否成功执行。
</ResponseField>

<ResponseField name="data" type="array of string" required>
已被至少一个启用渠道服务、但尚无模型元数据记录的模型名。所有启用模型都已有记录时序列化为 `null`；完全没有任何启用模型时返回空数组 `[]`。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。与其他模型接口不同，本接口成功响应不含 `message` 字段；失败时通过 `success: false` 加原始错误信息的 `message` 返回。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 数据库错误 | 读取启用模型或已有元数据失败，`message` 返回原始错误 |
