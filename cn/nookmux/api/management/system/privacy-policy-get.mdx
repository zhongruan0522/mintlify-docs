---
title: 获取隐私政策
description: 获取系统法律设置中配置的隐私政策文本。
api: "GET /api/privacy-policy"
---

返回管理员在系统法律设置中配置的隐私政策文本。该值以原始字符串返回，渲染由前端完成；未配置时返回空字符串（是否已配置的开关由状态接口的 `privacy_policy_enabled` 字段体现）。

该接口为公开接口，无需鉴权。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/privacy-policy'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": "# 隐私政策\n本站处理数据的方式 ..."
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  请求是否成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="string" required>
  系统法律设置中配置的隐私政策文本。未配置时为空字符串。
</ResponseField>
