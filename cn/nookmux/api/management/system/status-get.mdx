---
title: 获取系统状态
description: 获取登录前前端所需的公开引导配置：品牌信息、登录方式、面板开关与控制台内容。
api: "GET /api/status"
---

返回用于渲染登录前壳层并初始化前端的公开配置：品牌信息、可用登录方式、Turnstile 设置、面板开关、Passkey 参数以及可选的控制台内容（API 信息、公告、FAQ）。该响应对匿名与已登录调用者完全一致；管理员专属配置（侧栏模块结构、构建版本号）刻意不包含在内，由独立的管理端接口下发。

该接口为公开接口，无需鉴权。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/status'
```

</RequestExample>
