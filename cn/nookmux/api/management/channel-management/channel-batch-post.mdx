---
title: 批量删除渠道
description: 一次调用删除多个渠道及其路由能力记录。
api: "POST /api/channel/batch"
---

按 ID 批量删除渠道。渠道与其路由能力（abilities）在同一事务中删除（按每批 200 个 ID 分批处理），随后重新加载内存中的渠道缓存，并把该操作记入管理员审计日志。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/channel/batch' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "ids": [1, 2, 3]
}'
```

</RequestExample>

### 请求体

<ParamField path="body.ids" type="array" required>
  要删除的渠道 ID 列表，至少包含一个元素。
</ParamField>

<ParamField path="body.tag" type="string">
  本接口不使用该字段。请求结构体与批量设置标签接口共用，那里会接收可选的 `tag`；批量删除时该字段被忽略。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": 3
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  渠道是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="integer" required>
  请求中的 ID 数量。
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 参数无效 | JSON 格式错误或 `ids` 为空 |
| 数据库错误 | 事务删除失败，详见服务端日志 |
