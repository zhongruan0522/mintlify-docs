---
title: 获取渠道模型列表
description: 列出 NookMux 渠道适配器内置的全部模型。
api: "GET /api/channel/models"
---

返回 NookMux 内置的模型目录，由全部渠道适配器的模型清单（含 Moonshot 与 MiniMax 的内置清单）汇总并按模型 ID 去重。这是一个静态目录，不反映数据库中已配置的渠道。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/channel/models' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "data": [
    {
      "id": "gpt-4o",
      "object": "model",
      "created": 1626777600,
      "owned_by": "openai",
      "supported_endpoint_types": null
    },
    {
      "id": "claude-3-5-sonnet-20241022",
      "object": "model",
      "created": 1626777600,
      "owned_by": "claude",
      "supported_endpoint_types": null
    }
  ]
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  请求是否成功。
</ResponseField>

<ResponseField name="data" type="array" required>
  OpenAI 列表格式的内置模型条目。

  <Expandable title="data 条目结构">
    <ResponseField name="id" type="string" required>
      模型名。
    </ResponseField>
    <ResponseField name="object" type="string" required>
      固定为 `model`。
    </ResponseField>
    <ResponseField name="created" type="integer" required>
      固定的占位时间戳，所有条目相同。
    </ResponseField>
    <ResponseField name="owned_by" type="string" required>
      提供该模型的适配器名称，例如 `openai`、`claude`。
    </ResponseField>
    <ResponseField name="supported_endpoint_types" type="array">
      本接口不填充该字段，响应中恒为 `null`。
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。成功时不包含 `message` 字段。要查看当前渠道实际可路由的模型，请改用[获取已启用模型列表](/cn/nookmux/api/management/channel-management/channel-models_enabled-get)。
</Note>
