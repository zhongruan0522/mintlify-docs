---
title: 删除已禁用渠道
description: 一次性删除所有处于禁用状态（手动或自动）的渠道。
api: "DELETE /api/channel/disabled"
---

一次性删除所有状态为手动禁用（`2`）或自动禁用（`3`）的渠道，启用的渠道不受影响。删除完成后重新加载内存中的渠道缓存，并把该操作记入管理员审计日志。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/channel/disabled' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": 7
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  删除是否成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="integer" required>
  删除的渠道数量。
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。没有禁用渠道时 `data` 为 `0`。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 数据库错误 | 删除禁用渠道失败，详见服务端日志 |
