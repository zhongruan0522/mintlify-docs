---
title: 获取指定渠道
description: 按 ID 获取单个渠道的完整定义，不含上游密钥。
api: "GET /api/channel/{id}"
---

获取单个渠道的完整定义。响应中永远不会泄露上游 `key`（该字段恒为空字符串）；需要查看密钥请使用[获取渠道密钥](/cn/nookmux/api/management/channel-management/channel-id-key-post)。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/channel/1' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  渠道 ID。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
  请求是否成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
  渠道对象。`key` 字段恒为空字符串，不会泄露已存密钥。

  <Expandable title="channel 结构">
    <ResponseField name="id" type="integer" required>
      渠道 ID。
    </ResponseField>
    <ResponseField name="type" type="integer" required>
      渠道类型常量，例如 `1` 表示 OpenAI。
    </ResponseField>
    <ResponseField name="key" type="string">
      上游密钥。本响应中恒为空字符串，不会返回已存密钥值。
    </ResponseField>
    <ResponseField name="status" type="integer" required>
      `1` 启用，`2` 手动禁用，`3` 自动禁用。
    </ResponseField>
    <ResponseField name="name" type="string" required>
      渠道显示名称。
    </ResponseField>
    <ResponseField name="weight" type="integer" required>
      同优先级渠道之间的负载均衡权重。可能为 `null`。
    </ResponseField>
    <ResponseField name="created_time" type="integer" required>
      渠道创建时间的 Unix 时间戳（秒）。
    </ResponseField>
    <ResponseField name="test_time" type="integer" required>
      最近一次渠道测试的 Unix 时间戳；从未测试过为 `0`。
    </ResponseField>
    <ResponseField name="response_time" type="integer" required>
      最近一次渠道测试的延迟，单位毫秒。
    </ResponseField>
    <ResponseField name="base_url" type="string" required>
      自定义上游 Base URL。可能为 `null`。
    </ResponseField>
    <ResponseField name="other" type="string" required>
      渠道类型的附加选项，例如 Vertex AI 的区域 JSON。
    </ResponseField>
    <ResponseField name="balance" type="number" required>
      预估剩余余额，单位美元。
    </ResponseField>
    <ResponseField name="balance_updated_time" type="integer" required>
      最近一次余额更新的 Unix 时间戳。
    </ResponseField>
    <ResponseField name="models" type="string" required>
      该渠道支持的模型名列表，逗号分隔。
    </ResponseField>
    <ResponseField name="group" type="string" required>
      可使用该渠道的用户分组，逗号分隔。
    </ResponseField>
    <ResponseField name="used_quota" type="integer" required>
      该渠道累计消耗的配额。
    </ResponseField>
    <ResponseField name="model_mapping" type="string" required>
      模型名重定向的 JSON 对象。可能为 `null`。
    </ResponseField>
    <ResponseField name="status_code_mapping" type="string" required>
      上游 HTTP 状态码到 NookMux 返回状态码的映射 JSON 对象。可能为 `null`。
    </ResponseField>
    <ResponseField name="priority" type="integer" required>
      路由优先级。可能为 `null`。
    </ResponseField>
    <ResponseField name="auto_ban" type="integer" required>
      上游连续失败后是否自动禁用渠道：`1` 启用，`0` 关闭。可能为 `null`。
    </ResponseField>
    <ResponseField name="other_info" type="string" required>
      服务端维护的杂项运行信息。
    </ResponseField>
    <ResponseField name="tag" type="string" required>
      用于控制台分组的渠道标签。可能为 `null`。
    </ResponseField>
    <ResponseField name="setting" type="string" required>
      渠道运行时设置的 JSON 对象。可能为 `null`。
    </ResponseField>
    <ResponseField name="param_override" type="string" required>
      请求转发上游前的参数覆盖 JSON 对象。可能为 `null`。
    </ResponseField>
    <ResponseField name="header_override" type="string" required>
      追加或覆盖发往上游的请求头的 JSON 对象。可能为 `null`。
    </ResponseField>
    <ResponseField name="remark" type="string" required>
      自由备注。
    </ResponseField>
    <ResponseField name="channel_info" type="object" required>
      渠道密钥与套餐的运行信息。

      <Expandable title="channel_info 结构">
        <ResponseField name="is_multi_key" type="boolean" required>
          是否为聚合多个密钥的渠道。
        </ResponseField>
        <ResponseField name="multi_key_size" type="integer" required>
          多 Key 模式下的密钥数量。
        </ResponseField>
        <ResponseField name="multi_key_status_list" type="object" required>
          密钥索引到密钥状态的映射。
        </ResponseField>
        <ResponseField name="multi_key_polling_index" type="integer" required>
          轮询模式下一次使用的密钥索引。
        </ResponseField>
        <ResponseField name="multi_key_mode" type="string" required>
          多 Key 策略：`random`（随机）或 `polling`（轮询）。
        </ResponseField>
        <ResponseField name="is_plan" type="boolean" required>
          是否指向套餐计量的特殊 Base URL。
        </ResponseField>
        <ResponseField name="plan_name" type="string" required>
          套餐标识，对应已知的特殊 Base URL。
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="settings" type="string" required>
      额外设置的 JSON 对象，例如 Azure 的 API 版本。
    </ResponseField>
    <ResponseField name="openai_organization" type="string" required>
      OpenAI 类型渠道的 organization 头。可能为 `null`。
    </ResponseField>
    <ResponseField name="test_model" type="string" required>
      渠道测试所用的模型。可能为 `null`。
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。渠道 ID 不存在时以 `success: false` 的数据库错误返回。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 渠道 ID 格式错误 | 路径中的 `id` 不是整数 |
| 数据库错误 | 渠道加载失败，包括渠道不存在 |
