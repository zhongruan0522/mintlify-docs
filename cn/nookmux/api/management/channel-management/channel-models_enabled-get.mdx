---
title: 获取已启用模型列表
description: 列出当前至少有一个启用渠道的模型名（去重）。
api: "GET /api/channel/models_enabled"
---

返回当前至少存在一条启用路由能力的模型名（去重），即此刻启用渠道真正可提供服务的模型。数据取自 `abilities` 路由表。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/channel/models_enabled' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "data": [
    "gpt-4o",
    "gpt-4o-mini",
    "claude-3-5-sonnet-20241022"
  ]
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  请求是否成功。
</ResponseField>

<ResponseField name="data" type="array" required>
  至少有一条启用渠道能力的模型名（去重）。路由表为空时为 `null`。
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。成功时不包含 `message` 字段。静态适配器模型目录见[获取渠道模型列表](/cn/nookmux/api/management/channel-management/channel-models-get)。
</Note>
