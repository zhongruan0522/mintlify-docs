---
title: 获取上游供应商列表
description: 从已保存渠道的上游拉取 OpenRouter 供应商列表。
api: "GET /api/channel/fetch_providers/{id}"
---

从已保存的 OpenRouter 渠道的上游拉取供应商列表，供渠道表单的供应商选择器使用。请求渠道的 `{base_url}/v1/providers` 接口；渠道未设置自定义 Base URL 时使用内置的 OpenRouter 地址（`https://openrouter.ai/api`）。

该供应商接口是公开的，无需密钥。请求经渠道配置的代理发出。仅接受 OpenRouter（`20`）类型的渠道。slug 为空的条目会被丢弃，`slug`/`name` 的值会做首尾去空白。

需要**超级管理员（Root）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/channel/fetch_providers/1' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  要查询上游的 OpenRouter 渠道 ID。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": [
    {
      "slug": "openai",
      "name": "OpenAI",
      "headquarters": "San Francisco, CA, USA",
      "privacy_policy_url": "https://openai.com/policies/privacy-policy/"
    },
    {
      "slug": "anthropic",
      "name": "Anthropic"
    }
  ]
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  供应商列表是否拉取成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="array" required>
  上游返回的供应商条目列表。

  <Expandable title="provider 结构">
    <ResponseField name="slug" type="string" required>
      供应商标识，用于 OpenRouter 模型 ID，例如 `openrouter/openai/gpt-4o` 中的 `openai`。
    </ResponseField>
    <ResponseField name="name" type="string">
      供应商显示名称。
    </ResponseField>
    <ResponseField name="headquarters" type="string">
      供应商总部所在地。上游未提供时省略。
    </ResponseField>
    <ResponseField name="privacy_policy_url" type="string">
      供应商隐私政策 URL。上游未提供时省略。
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 渠道ID格式错误 | 路径中的 `id` 不是整数 |
| 数据库错误，请稍后重试 | 渠道加载失败，包括渠道不存在的情况 |
| 此操作仅支持 OpenRouter 渠道 | 渠道类型不是 OpenRouter |
| 获取供应商失败 | 上游请求失败或返回非 200 状态码 |
| 解析响应失败 | 上游响应无法解析为供应商列表 |
