---
title: 查询 GLM 重置卡列表
description: 查询 GLM 套餐可用的额度重置卡，按重置类型分组。
api: "GET /api/channel/plan/glm/reset_cards/{id}"
---

查询 GLM 套餐可用的额度重置卡。渠道必须是套餐为 `glm-coding-plan` 或 `glm-coding-plan-international` 的套餐渠道；上游域名按套餐区域划分（国内套餐走 `bigmodel.cn`，国际套餐走 `api.z.ai`）。上游查询固定面向个人账户（`targetType` 为 `PERSONAL`，由服务端固定）。

卡列表按智谱官网前端的逻辑归一化：保留未使用的卡与近 7 天内过期的卡，更早过期的丢弃；可用卡按 `expireTime` 升序排列，首张标记 `priority`。消费卡片请使用[使用 GLM 重置卡](/cn/nookmux/api/management/channel-management/channel-plan-glm-reset_cards-id-use-post)。

需要**管理员**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/channel/plan/glm/reset_cards/1' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
渠道 ID。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "data": {
    "fiveHourResets": [
      {
        "recordId": 1001,
        "expireTime": "2026-11-01 00:00:00",
        "available": true,
        "priority": true
      },
      {
        "recordId": 1002,
        "expireTime": "2026-11-15 00:00:00",
        "available": false
      }
    ],
    "weekResets": []
  }
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
请求是否成功。
</ResponseField>

<ResponseField name="data" type="object" required>
按重置类型分组的重置卡列表。

<Expandable title="data 结构">
  <ResponseField name="fiveHourResets" type="object[]" required>
    重置 5 小时额度的卡；无卡时为空数组。结构见下方卡结构。
  </ResponseField>
  <ResponseField name="weekResets" type="object[]" required>
    重置每周额度的卡（同时重置 5 小时额度）；无卡时为空数组。卡结构相同。
    <Expandable title="card 结构">
      <ResponseField name="recordId" type="integer" required>
        卡记录 ID，使用端点以 `recordId` 提交。
      </ResponseField>
      <ResponseField name="expireTime" type="string" required>
        卡过期时间，格式为上游返回的 `YYYY-MM-DD HH:MM:SS` 或 RFC3339。
      </ResponseField>
      <ResponseField name="available" type="boolean" required>
        卡是否仍可使用。
      </ResponseField>
      <ResponseField name="priority" type="boolean">
        同组内首张可用卡（最快过期）标记为 `true`；其余省略。
      </ResponseField>
    </Expandable>
  </ResponseField>
</Expandable>
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。本端点成功时仅返回 `success` 与 `data`（不含 `message` 字段）；失败时返回 `success: false` 与本地化的 `message`。
</Note>

## 错误说明

| 条件 | message 文案 | 说明 |
| --- | --- | --- |
| 参数错误 | `参数错误` | 路径中的 `id` 缺失或不是整数 |
| 渠道不存在 | `渠道不存在` | 渠道不存在或加载失败 |
| 非套餐渠道 | `该渠道不是套餐渠道` | `channel_info.is_plan` 为 `false` |
| 不支持重置卡查询 | `该渠道不支持重置卡查询` | 渠道套餐不是 `glm-coding-plan` 或 `glm-coding-plan-international` |
| 渠道密钥无效 | `渠道 API Key 无效或认证失败，请检查 Key 配置` | 上游拒绝该密钥 |
| 查询重置卡失败 | `查询重置卡失败: {{.Error}}` | 上游请求或响应解析失败；`{{.Error}}` 为底层错误详情 |
