---
title: 启用标签渠道
description: 重新启用携带指定标签的全部渠道。
api: "POST /api/channel/tag/enabled"
---

启用携带指定标签的全部渠道。每个匹配渠道的状态会被置为 `1`（启用），并同步启用这些渠道路由能力，请求可再次路由到它们。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/channel/tag/enabled' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "tag": "openai-pool"
}'
```

</RequestExample>

### 请求体

<ParamField path="body.tag" type="string" required>
要启用的渠道标签，按标签精确匹配。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": ""
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
渠道是否启用成功。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。该操作会同时清除匹配渠道的手动禁用与自动禁用状态。变更完成后渠道缓存会立即刷新。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 请求参数非法 | JSON 缺失、格式错误，或 `tag` 为空 |
| 数据库错误 | 状态变更落库失败，详见服务端日志 |
