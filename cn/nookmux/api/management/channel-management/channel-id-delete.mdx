---
title: 删除渠道
description: 按 ID 删除单个渠道及其路由能力记录。
api: "DELETE /api/channel/{id}"
---

删除单个渠道。渠道记录与其路由能力（abilities）在同一次数据库操作中一并删除，随后重新加载内存中的渠道缓存，并把该删除操作记入管理员审计日志。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/channel/1' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  要删除的渠道 ID。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": ""
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  渠道是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<Note>
  管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。删除不存在的 ID 同样视为成功。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 数据库错误 | 删除渠道或其能力记录失败，详见服务端日志 |
