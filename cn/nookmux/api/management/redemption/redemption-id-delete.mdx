---
title: 删除兑换码
description: 按 id 软删除单个兑换码。
api: "DELETE /api/redemption/{id}"
---

按 id 删除单个兑换码。删除为软删除：记录被标记为已删除后不再出现在列表、搜索与详情查询中。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/redemption/42' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  待删除兑换码的 id。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": ""
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  兑换码是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。本响应不携带 `data` 字段。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 数据库错误 | `id` 缺失、不是数字或不存在对应兑换码，详见服务端日志 |
