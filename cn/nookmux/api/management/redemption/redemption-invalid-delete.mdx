---
title: 删除无效兑换码
description: 批量清理已使用、已禁用或已过期的兑换码，并返回删除条数。
api: "DELETE /api/redemption/invalid"
---

批量删除全部不可再兑换的兑换码：状态为已使用（`3`）或禁用（`2`）的兑换码，以及状态为启用（`1`）但已设置过期时间且过期时间早于当前的兑换码。删除的条数通过 `data` 返回。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/redemption/invalid' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": 12
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  删除是否成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="integer" required>
  本次调用删除的兑换码条数；无可清理数据时为 `0`。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 数据库错误 | 删除无效兑换码失败，详见服务端日志 |
