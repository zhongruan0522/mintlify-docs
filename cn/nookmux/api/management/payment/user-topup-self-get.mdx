---
title: 获取用户充值记录
description: 分页返回当前用户的在线充值订单，支持按订单号搜索。
api: "GET /api/user/topup/self"
---

分页返回当前用户的在线充值订单，按时间倒序排列，支持按订单号关键字搜索。

需要**用户（User）**权限（任意已登录账号）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

<Note>
历史记录仅保留最近 30 天，但待支付订单不受时间窗口限制、始终可见，便于用户找回支付回调丢失的订单并自查支付状态。
</Note>

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/user/topup/self?p=1&page_size=10&keyword=USR1NO' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 查询参数

<ParamField path="p" type="integer" default="1">
页码，从 1 开始。
</ParamField>

<ParamField path="page_size" type="integer" default="10">
页大小，最大 100。`page_size` 缺省时也接受旧别名 `ps` 与 `size`。
</ParamField>

<ParamField path="keyword" type="string">
按订单号（`trade_no`）匹配的搜索关键字。缺省时返回完整列表。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
充值记录是否加载成功。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
分页信息包裹结构。

<Expandable title="data 结构">
  <ParamField path="page" type="integer" required>
    当前页码。
  </ParamField>
  <ParamField path="page_size" type="integer" required>
    实际生效的页大小（经默认值与 100 上限处理后的值）。
  </ParamField>
  <ParamField path="total" type="integer" required>
    符合条件的记录总数。
  </ParamField>
  <ParamField path="items" type="array" required>
    当前页的充值订单，按 `id` 降序排列。
  </ParamField>
</Expandable>
</ResponseField>

<ResponseField name="data.items[]" type="object" required>
单条充值订单记录。

<Expandable title="充值订单结构">
  <ParamField path="id" type="integer" required>
    记录 ID。
  </ParamField>
  <ParamField path="user_id" type="integer" required>
    订单所属用户 ID（即当前用户）。
  </ParamField>
  <ParamField path="amount" type="integer" required>
    订单的充值数量。
  </ParamField>
  <ParamField path="money" type="number" required>
    下单时计算出的应付金额。
  </ParamField>
  <ParamField path="trade_no" type="string" required>
    订单号。易支付订单为 `USR{user_id}NO...` 形式；Stripe 订单为 `ref_` 前缀的哈希。
  </ParamField>
  <ParamField path="payment_method" type="string" required>
    订单的支付渠道，例如 `alipay`、`wxpay` 或 `stripe`。
  </ParamField>
  <ParamField path="payment_provider" type="string" required>
    支付提供方：易支付订单为 `epay`，Stripe 订单为 `stripe`。
  </ParamField>
  <ParamField path="create_time" type="integer" required>
    订单创建时间，Unix 时间戳（秒）。
  </ParamField>
  <ParamField path="complete_time" type="integer" required>
    订单完成时间，Unix 时间戳（秒）；未完成时为 `0`。
  </ParamField>
  <ParamField path="status" type="string" required>
    订单状态：`pending`（待支付）、`success`（成功）、`expired`（过期）或 `failed`（失败）。
  </ParamField>
</Expandable>
</ResponseField>
