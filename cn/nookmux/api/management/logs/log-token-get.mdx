---
title: 按令牌密钥查询日志
description: 查询 Authorization 请求头所携带令牌密钥的用量日志，支持分页与旧版数组两种响应。
api: "GET /api/log/token"
---

返回请求所携带的 API 令牌的用量日志。令牌 id 由认证上下文强制注入，调用方无法查询其他令牌的日志。本接口通过令牌密钥本身鉴权——`Authorization` 请求头必须携带令牌密钥（例如 `sk-xxxx`），而不是管理访问令牌。

令牌由只读令牌鉴权中间件解析，只校验密钥是否存在：已禁用、已过期或额度耗尽的令牌同样允许访问；被封禁的用户会被拒绝。管理接口的通用鉴权模型参见[身份认证](/cn/nookmux/api/management/auth)。

<Note>
本路由受严格的关键操作限流保护，并允许跨域请求（CORS）。传入 `p` 或 `page_size` 任意一个即切换到分页响应；两者都缺省时保留旧版的近期日志数组响应。
</Note>

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/log/token?p=1&page_size=10&type=2&model_name=gpt-4o' \
  --header 'Authorization: Bearer sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx'
```

</RequestExample>

### 请求头

<ParamField path="header.Authorization" type="string" required>
  API 令牌密钥，形如 `Bearer sk-xxxx`。
</ParamField>

### 查询参数

<ParamField path="query.p" type="integer" default="1">
  页码。传入 `p` 或 `page_size` 任意一个即切换到分页响应。
</ParamField>

<ParamField path="query.page_size" type="integer" default="10">
  每页条数，上限 100。分页助手同时兼容旧别名 `ps` 与 `size`。
</ParamField>

<ParamField path="query.type" type="integer">
  日志类型：`1` 充值、`2` 消费、`3` 管理、`4` 系统、`5` 错误、`6` 退款。缺省或 `0` 匹配全部类型。仅在分页模式下生效。
</ParamField>

<ParamField path="query.start_timestamp" type="integer">
  Unix 时间戳（秒）；只返回 `created_at` 大于等于该值的日志。`0`（默认）表示不限下界。仅在分页模式下生效。
</ParamField>

<ParamField path="query.end_timestamp" type="integer">
  Unix 时间戳（秒）；只返回 `created_at` 小于等于该值的日志。`0`（默认）表示不限上界。仅在分页模式下生效。
</ParamField>

<ParamField path="query.model_name" type="string">
  模型名匹配模式；允许 `%` 通配符（最多两个、不得连续、去掉 `%` 后关键词至少 2 个字符），`_` 与 `!` 按字面匹配。不含 `%` 时按模型名精确匹配。仅在分页模式下生效。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
  请求是否成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data.page" type="integer" required>
  当前页码。仅分页模式返回。
</ResponseField>

<ResponseField name="data.page_size" type="integer" required>
  实际生效的每页条数。仅分页模式返回。
</ResponseField>

<ResponseField name="data.total" type="integer" required>
  匹配的日志总数，上限 10000。仅分页模式返回。
</ResponseField>

<ResponseField name="data.items" type="array" required>

<Note>
旧版数组模式：`p` 与 `page_size` 都缺省时，`data` 直接为该令牌最近最多 1000 条日志的数组（log 结构与脱敏规则相同，`id` 从 1 起编号），而非分页对象；类型、时间与模型过滤在该模式下不生效。
</Note>

<Note>
管理接口在业务失败时同样返回 HTTP `200`；本路由的鉴权失败返回 HTTP `401` / `403` / `500`。
</Note>

## 错误说明

| 条件 | 状态码 | 说明 |
| --- | --- | --- |
| 缺少 Authorization 请求头 | `401` | `Authorization` 请求头缺失 |
| 无效的令牌 | `401` | 密钥未匹配到任何令牌 |
| 用户已被封禁 | `403` | 令牌所属用户已被禁用 |
| 数据库错误，请稍后重试 | `500` | 加载令牌所属用户的用户缓存失败 |
| 数据库错误，请稍后重试 | `200` | 查询或统计日志失败，详见服务端日志 |
