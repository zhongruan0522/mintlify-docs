---
title: 删除音色
description: 按主键 ID 删除音色记录。
api: "DELETE /api/custom_voice/voices/{id}"
---

永久删除指定主键 ID 的音色记录。删除后该音色 ID 立即从 TTS 白名单移除，引用该 ID 的 TTS 请求不再被接受。

需要**超级管理员（Root）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/custom_voice/voices/3' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
  音色记录的主键。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": ""
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  音色记录是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。成功时不返回 `data` 字段。该接口额外存在两类非 200 响应：`id` 不是合法整数时返回 HTTP `400`，记录不存在时返回 HTTP `404`。删除成功会计入管理员审计日志（音色模块）。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 音色ID不合规（HTTP 400） | `id` 不是合法整数 |
| 音色不存在（HTTP 404） | 给定 `id` 的记录不存在 |
| 数据库错误，请稍后重试 | 记录查询或删除失败，详见服务端日志 |
