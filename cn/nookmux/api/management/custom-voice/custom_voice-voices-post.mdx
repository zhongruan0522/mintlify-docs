---
title: 创建音色
description: 手动创建音色记录，常用于白名单收录或重定向上游音色。
api: "POST /api/custom_voice/voices/"
---

直接创建音色记录，不经过用户试听/确认流程。可用于将上游音色收录进 TTS 白名单，必要时通过 `redirect_id` 让对外暴露一个不同的音色 ID。

操作人记录为当前管理员（`operator_kind` 为 `admin`），`quota_cost` 为 `0`。音色 ID 重复时以统一的"不合规"错误拒绝，不暴露重复信息。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/custom_voice/voices/' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "voice_id": "official-voice-001",
  "type": "created",
  "redirect_id": "minimax-voice-0000",
  "allowed": true,
  "remark": "Official voice"
}'
```

</RequestExample>

### 请求体

<ParamField path="body.voice_id" type="string" required>
  对外音色 ID，TTS 请求引用该 ID；使用前去除首尾空白，全表唯一，不能为空。
</ParamField>

<ParamField path="body.type" type="string" default="created">
  音色类型：`preview` 或 `created`。省略或为空时默认 `created`。
</ParamField>

<ParamField path="body.redirect_id" type="string">
  发往上游的真实音色 ID；使用前去除首尾空白。留空表示直接把 `voice_id` 发给上游。
</ParamField>

<ParamField path="body.allowed" type="boolean" default="false">
  是否允许用于 TTS。仅对 `created` 类型生效。
</ParamField>

<ParamField path="body.remark" type="string">
  自由备注，最长 255 字符。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
  音色记录是否创建成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
  创建的音色记录。`created_at` 与 `updated_at` 由服务端写入，`operator_id` 为当前管理员 ID，`operator_kind` 为 `admin`。

  <Expandable title="voice 结构">
    <ResponseField name="id" type="integer" required>
      记录主键。
    </ResponseField>
    <ResponseField name="created_at" type="integer" required>
      创建时间的 Unix 时间戳（秒）。
    </ResponseField>
    <ResponseField name="updated_at" type="integer" required>
      最近更新时间的 Unix 时间戳（秒）。
    </ResponseField>
    <ResponseField name="type" type="string" required>
      音色类型：`preview` 或 `created`。
    </ResponseField>
    <ResponseField name="operator_id" type="integer" required>
      创建该记录的管理员 ID。
    </ResponseField>
    <ResponseField name="operator_kind" type="string" required>
      经本接口创建的记录恒为 `admin`。
    </ResponseField>
    <ResponseField name="voice_id" type="string" required>
      对外音色 ID，TTS 请求引用该 ID。
    </ResponseField>
    <ResponseField name="quota_cost" type="integer" required>
      管理员创建的记录恒为 `0`。
    </ResponseField>
    <ResponseField name="redirect_id" type="string" required>
      发往上游的真实音色 ID；为空表示直接把 `voice_id` 发给上游。
    </ResponseField>
    <ResponseField name="allowed" type="boolean" required>
      是否允许用于 TTS。
    </ResponseField>
    <ResponseField name="remark" type="string" required>
      自由备注；可能为空字符串。
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。JSON 请求体缺失或格式错误时返回 HTTP `400`。创建成功会计入管理员审计日志（音色模块）。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 无效的参数（HTTP 400） | JSON 请求体缺失或格式错误 |
| 音色ID不能为空 | `voice_id` 去除首尾空白后为空 |
| 音色类型不合规 | `type` 不是 `preview` 或 `created` |
| 音色ID不合规 | `voice_id` 已存在（按不合规提示，不暴露重复） |
| 数据库错误，请稍后重试 | 查重或写入失败，详见服务端日志 |
