---
title: 强制执行垃圾回收
description: 在网关进程中触发一次完整的垃圾回收。
api: "POST /api/performance/gc"
---

在 NookMux 进程中执行一次完整的垃圾回收（Go 运行时 `runtime.GC`），完成后才返回响应。适用于清理缓存或处理大批量数据后将内存归还操作系统。该操作会记入审计日志。

需要**超级管理员（Root）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/performance/gc' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "GC 已执行"
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  垃圾回收是否执行成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  成功时为确认文案（按调用者语言偏好本地化）。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。本接口没有业务失败分支。垃圾回收在返回响应前同步执行完成。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 鉴权失败 | 调用者不是 Root 用户时返回标准鉴权错误（HTTP `401`） |
