---
title: 重置性能统计
description: 将累计的磁盘缓存与内存缓存命中计数清零。
api: "POST /api/performance/reset_stats"
---

将 `GET /api/performance/stats` 返回的累计命中计数器 `disk_cache_hits` 与 `memory_cache_hits` 清零。活跃文件数、当前用量等其他计数器不受影响。该操作会记入审计日志。

需要**超级管理员（Root）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/performance/reset_stats' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "统计信息已重置"
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  命中计数器是否重置成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  成功时为确认文案（按调用者语言偏好本地化）。
</ResponseField>

<Note>
管理接口在业务失败时同样返回 HTTP `200`，必须以 `success` 字段判断结果。本接口没有业务失败分支。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 鉴权失败 | 调用者不是 Root 用户时返回标准鉴权错误（HTTP `401`） |
