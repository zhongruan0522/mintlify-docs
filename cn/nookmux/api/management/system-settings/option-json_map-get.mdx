---
title: 获取 JSON 映射配置项
description: 分页列出 JSON 映射型系统选项的条目，支持关键字过滤。
api: "GET /api/option/json_map"
---

返回 JSON 对象型系统选项的条目，以分页的 `key`/`value` 列表形式给出。支持两类键：MiniMax 重定向选项（`minimax.model_redirect`、`minimax.emotion_redirect`、`minimax.tone_word_redirect`，其值为普通字符串映射）与计价选项（`ModelPrice`、`ModelRatio`、`CacheRatio`、`CreateCacheRatio`、`CompletionRatio`、`AudioRatio`、`AudioCompletionRatio`、`ContextPricing`，其每个模型的值为数字或嵌套 JSON）。条目按映射键升序排序；存储值缺失或为空白时按 `{}` 处理。

需要**超级管理员（Root）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/option/json_map?key=ModelRatio&page=1&page_size=10&keyword=gpt-4o' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 查询参数

<ParamField path="key" type="string" required>
  要读取的选项键。必须是受支持的 JSON 映射键之一：`minimax.model_redirect`、`minimax.emotion_redirect`、`minimax.tone_word_redirect`、`ModelPrice`、`ModelRatio`、`CacheRatio`、`CreateCacheRatio`、`CompletionRatio`、`AudioRatio`、`AudioCompletionRatio`、`ContextPricing`。
</ParamField>

<ParamField path="page" type="integer" default="1">
  页码，从 1 开始。不是正整数时回退为 `1`；超出最后一页时返回最后一页。
</ParamField>

<ParamField path="page_size" type="integer" default="10">
  每页条目数。不是正整数时回退为 `10`；超过 `100` 时按 `100` 处理。
</ParamField>

<ParamField path="keyword" type="string">
  子串过滤。仅返回映射键或值包含该关键字（去除首尾空白后）的条目；省略时返回全部条目。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "",
  "data": {
    "items": [
      {
        "key": "gpt-4o",
        "value": "2.5"
      },
      {
        "key": "gpt-4o-mini",
        "value": "0.15"
      }
    ],
    "page": 1,
    "page_size": 10,
    "total": 2
  }
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  条目是否读取成功。
</ResponseField>

<ResponseField name="message" type="string" required>
  `success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object" required>
  分页的条目列表。

  <Expandable title="data 结构">
    <ResponseField name="items" type="array" required>
      当前页的条目。

      <Expandable title="条目结构">
        <ResponseField name="key" type="string" required>
          JSON 对象内的条目键，例如模型名。
        </ResponseField>
        <ResponseField name="value" type="string" required>
          条目值的字符串形式。MiniMax 选项为普通映射字符串；计价选项为条目值的原始 JSON 文本（数字形如 `"2.5"`）。
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="page" type="integer" required>
      钳制到有效范围后的当前页码。
    </ResponseField>
    <ResponseField name="page_size" type="integer" required>
      实际生效的每页条目数（默认 `10`，上限 `100`）。
    </ResponseField>
    <ResponseField name="total" type="integer" required>
      命中过滤条件的条目总数。
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  参数错误使用真实 HTTP 状态码：`key` 不受支持时返回 HTTP `400`。存储的选项值 JSON 解析失败时返回 HTTP `200` 加 `success: false`，`message` 中为解析错误。如需逐条修改这些选项，请使用[更新系统选项](/cn/nookmux/api/management/system-settings/option-put)或 JSON 映射写入接口。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 不支持的 JSON 映射配置项 | HTTP `400`；`key` 不是受支持的 JSON 映射选项键 |
| `JSON 映射配置解析失败: {Error}` | HTTP `200` 加 `success: false`；存储的选项值不是合法 JSON |
