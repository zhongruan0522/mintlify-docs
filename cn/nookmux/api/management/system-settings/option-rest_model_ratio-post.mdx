---
title: 重置模型倍率
description: 将 ModelRatio 选项恢复为内置的默认模型倍率表。
api: "POST /api/option/rest_model_ratio"
---

把 `ModelRatio` 选项重置为内置默认倍率表。默认 JSON 通过选项存储持久化（写库并刷新内存），并重新应用到计费运行时，所有模型的定价立即回退到默认值。该操作会以选项更新类型记入管理员审计日志。

无需请求体。

需要**超级管理员（Root）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/option/rest_model_ratio' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "重置模型倍率成功",
  "data": null
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
  重置是否完成。
</ResponseField>

<ResponseField name="message" type="string" required>
  成功时为 `重置模型倍率成功`；`success` 为 `false` 时为错误描述。
</ResponseField>

<ResponseField name="data" type="null" required>
  恒为 `null`；本端点不返回数据载荷。
</ResponseField>

<Note>
  自定义模型倍率会被直接覆盖且无二次确认；如需恢复请通过 `PUT /api/option/` 手动写回。持久化或运行时重应用任一步失败时，接口返回 `success: false` 且 `message` 为原始错误文本；两步都成功后才写入审计条目。
</Note>
