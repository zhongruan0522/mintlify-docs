---
title: 获取签到状态
description: 返回当前用户的签到配置、当月签到记录与累计统计。
api: "GET /api/user/checkin"
---

返回当前登录用户的每日签到状态：全局配置的额度奖励区间、指定月份的签到记录与全量统计。签到功能必须在服务端开启；未开启时接口直接返回错误而不是数据。

需要**用户**权限（任意登录用户）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/user/checkin?month=2026-10' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 2'
```

</RequestExample>

### 查询参数

<ParamField path="month" type="string" default="当前月份">
要查询的月份，格式 `YYYY-MM`。缺省为当前月份。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
状态是否加载成功。
</ResponseField>

<ResponseField name="data" type="object" required>
当前用户的签到状态。

<Expandable title="data 结构">
  <ParamField path="enabled" type="boolean" required>
    签到功能是否开启；成功响应中恒为 `true`。
  </ParamField>
  <ParamField path="min_quota" type="integer" required>
    每次签到随机额度奖励的下界。服务端默认 `1000`（约 0.002 美元），由管理员配置。
  </ParamField>
  <ParamField path="max_quota" type="integer" required>
    每次签到随机额度奖励的上界。服务端默认 `10000`（约 0.02 美元），由管理员配置。
  </ParamField>
  <ParamField path="stats" type="object" required>
    签到统计信息，结构见下方可展开部分。
  </ParamField>
</Expandable>
</ResponseField>

<ResponseField name="data.stats" type="object" required>
当前用户的签到统计。

<Expandable title="stats 结构">
  <ParamField path="total_quota" type="integer" required>
    所有时间通过签到累计获得的额度。
  </ParamField>
  <ParamField path="total_checkins" type="integer" required>
    所有时间的累计签到次数。
  </ParamField>
  <ParamField path="checkin_count" type="integer" required>
    查询月份内的签到次数。
  </ParamField>
  <ParamField path="checked_in_today" type="boolean" required>
    今天是否已签到。
  </ParamField>
  <ParamField path="records" type="array" required>
    查询月份的签到记录，按 `checkin_date` 倒序排列。
  </ParamField>
</Expandable>
</ResponseField>

<ResponseField name="data.stats.records[]" type="object" required>
单条签到记录。

<Expandable title="records[] 结构">
  <ParamField path="checkin_date" type="string" required>
    签到日期，格式 `YYYY-MM-DD`。
  </ParamField>
  <ParamField path="quota_awarded" type="integer" required>
    该次签到获得的额度。
  </ParamField>
</Expandable>
</ResponseField>

<Note>
本接口成功响应中省略了 `message` 字段，偏离管理接口惯用的 `{success, message, data}` 包裹结构。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 签到功能未启用 | 服务端未开启签到功能 |
| 数据库错误 | 读取签到记录失败，返回原始错误文本，详见服务端日志 |
