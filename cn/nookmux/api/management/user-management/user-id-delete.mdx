---
title: 删除用户
description: 按 ID 硬删除用户，物理移除数据行，不经过软删除。
api: "DELETE /api/user/{id}"
---

永久删除一个用户。与用户自助注销接口不同，这里是硬删除：数据行被物理移除，无法恢复。调用者角色必须严格高于目标用户，因此超级管理员账号无法被任何人删除（包括另一位超级管理员）。操作会写入审计日志。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request DELETE \
  --url 'https://your-nookmux-domain/api/user/2' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 路径参数

<ParamField path="path.id" type="integer" required>
要删除的用户 ID。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": ""
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
用户是否删除成功。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<Note>
本接口不返回 `data` 字段。若需要可恢复的软删除，请使用自助接口 `DELETE /api/user/self` 或 `POST /api/user/manage` 的 `delete` 动作。
</Note>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 参数非法 | 路径中的 `id` 不是整数 |
| 数据库错误 | 目标用户加载失败（含 `id` 不存在）或删除失败 |
| 无权限 | 目标用户角色等级等于或高于调用者 |
