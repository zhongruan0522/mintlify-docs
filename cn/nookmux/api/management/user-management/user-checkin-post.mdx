---
title: 执行签到
description: 完成今日签到并获得随机额度奖励。
api: "POST /api/user/checkin"
---

为当前登录用户执行每日签到。成功后在配置的 `min_quota` 与 `max_quota`（含边界）之间随机发放一次额度奖励，并生成今日的签到记录。每个用户每天最多签到一次。

需要**用户**权限（任意登录用户）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

<Note>
服务端开启 Cloudflare Turnstile 校验时，本接口受其保护：需在 `turnstile` 查询参数中携带有效的 Turnstile token（例如 `POST /api/user/checkin?turnstile={token}`），或复用已通过校验的会话。缺少有效 token 的请求会在签到前被拒绝。
</Note>

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://your-nookmux-domain/api/user/checkin' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 2'
```

</RequestExample>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "签到成功",
  "data": {
    "quota_awarded": 6500,
    "checkin_date": "2026-10-26"
  }
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
签到是否成功。
</ResponseField>

<ResponseField name="message" type="string" required>
成功时为本地化的成功提示；`success` 为 `false` 时为错误描述。
</ResponseField>

<ResponseField name="data" type="object" required>
签到结果。

<Expandable title="data 结构">
  <ParamField path="quota_awarded" type="integer" required>
    本次签到获得的额度，在 `GET /api/user/checkin` 返回的 `[min_quota, max_quota]` 区间内均匀随机。
  </ParamField>
  <ParamField path="checkin_date" type="string" required>
    签到归属日期，格式 `YYYY-MM-DD`。
  </ParamField>
</Expandable>
</ResponseField>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 签到功能未启用 | 服务端未开启签到功能 |
| 今日已签到 | 用户今天已经签到，消息为固定文案 `今日已签到` |
| 签到失败 | 签到记录创建失败或额度发放失败，消息为固定文案（`签到失败，请稍后重试` 或 `签到失败：更新额度出错`），详见服务端日志 |
| Turnstile token 为空 | 开启 Turnstile 后未携带 `turnstile` 查询参数，消息为固定文案 `Turnstile token 为空` |
| Turnstile 校验失败 | Turnstile token 被 Cloudflare 拒绝，消息为固定文案 `Turnstile 校验失败，请刷新重试！` |
