---
title: 更新Passkey
description: 按 ID 修改当前用户某个 Passkey 凭据的设备名称。
api: "PUT /api/user/passkey/{id}"
---

修改单个 Passkey（WebAuthn）凭据的设备名称。凭据必须属于调用者本人。新名称会去除首尾空白并截断到 255 字符；传空字符串会清空设备名称。

需要**用户**权限（任意登录用户）。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

<Note>
与其他 Passkey 接口相同，本接口从服务端会话 Cookie 解析用户，仅用 Access Token 鉴权会被拒绝并返回 HTTP `401`。
</Note>

## 请求

<RequestExample>

```bash cURL
curl --request PUT \
  --url 'https://your-nookmux-domain/api/user/passkey/1' \
  --header 'Cookie: session={session_cookie}' \
  --header 'New-Api-User: 1' \
  --header 'Content-Type: application/json' \
  --data '{
  "device_name": "My YubiKey"
}'
```

</RequestExample>

### 路径参数

<ParamField path="id" type="integer" required>
要改名的 Passkey 凭据 ID。
</ParamField>

### 请求体

<ParamField path="body.device_name" type="string" required>
凭据的新设备名称。去除首尾空白并截断到 255 字符；传空值会清空名称。
</ParamField>

## 响应

<ResponseExample>

```json 200
{
  "success": true,
  "message": "Passkey 已更新",
  "data": null
}
```

</ResponseExample>

### 响应字段

<ResponseField name="success" type="boolean" required>
凭据是否更新成功。
</ResponseField>

<ResponseField name="message" type="string" required>
成功时为本地化的成功提示；`success` 为 `false` 时为错误描述。
</ResponseField>

<ResponseField name="data" type="null">
本接口恒为 `null`。
</ResponseField>

## 错误说明

| 条件 | 说明 |
| --- | --- |
| 未登录 / 用户被禁用 | 会话无法解析，返回 HTTP `401` |
| 无效的 Passkey ID | 路径中的 `{id}` 不是整数 |
| 无权修改此 Passkey | 凭据属于其他用户，返回 HTTP `403` |
| 请求参数错误 | JSON 请求体缺失或格式错误 |
| 数据库错误，请稍后重试 | 凭据加载或更新失败，详见服务端日志 |
