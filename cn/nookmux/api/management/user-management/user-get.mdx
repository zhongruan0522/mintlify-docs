---
title: 获取所有用户
description: 分页列出全部用户，包含软删除的账号。
api: "GET /api/user/"
---

分页返回全部用户列表，按 `id` 降序排列。列表包含软删除的账号，`total` 计数同样包含它们。密码与访问令牌永不返回。

需要**管理员（Admin）**权限。管理接口的鉴权方式参见[身份认证](/cn/nookmux/api/management/auth)。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://your-nookmux-domain/api/user/?p=1&page_size=10' \
  --header 'Authorization: Bearer {access_token}' \
  --header 'New-Api-User: 1'
```

</RequestExample>

### 查询参数

<ParamField path="query.p" type="integer" default="1">
页码，从 1 开始。
</ParamField>

<ParamField path="query.page_size" type="integer" default="10">
每页用户数，上限 100。兼容旧参数名 `ps` 与 `size`。
</ParamField>

### 响应字段

<ResponseField name="success" type="boolean" required>
是否成功返回列表。
</ResponseField>

<ResponseField name="message" type="string" required>
`success` 为 `false` 时的错误描述；成功时为空字符串。
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="data 结构">
    <ResponseField name="page" type="integer" required>
      当前页码，从 1 开始。
    </ResponseField>
    <ResponseField name="page_size" type="integer" required>
      实际生效的每页数量，上限 100。
    </ResponseField>
    <ResponseField name="total" type="integer" required>
      用户总数，包含软删除账号。
    </ResponseField>
    <ResponseField name="items" type="object[]">
      当前页的用户列表，按 `id` 降序排列。

      <Expandable title="user 结构">
        <ResponseField name="id" type="integer" required>
          用户 ID。
        </ResponseField>
        <ResponseField name="username" type="string" required>
          登录用户名，最长 20 字符。
        </ResponseField>
        <ResponseField name="original_password" type="string" required>
          改密校验用的请求辅助字段；响应中恒为空字符串。
        </ResponseField>
        <ResponseField name="display_name" type="string" required>
          显示名称，最长 20 字符。
        </ResponseField>
        <ResponseField name="role" type="integer" required>
          角色等级：`1` 普通用户，`10` 管理员，`100` 超级管理员。
        </ResponseField>
        <ResponseField name="status" type="integer" required>
          账号状态：`1` 启用，`2` 禁用。
        </ResponseField>
        <ResponseField name="email" type="string" required>
          绑定的邮箱地址；未绑定时为空字符串。
        </ResponseField>
        <ResponseField name="github_id" type="string" required>
          绑定的 GitHub ID；未绑定时为空字符串。
        </ResponseField>
        <ResponseField name="verification_code" type="string" required>
          邮箱验证用的请求辅助字段；响应中恒为空字符串。
        </ResponseField>
        <ResponseField name="quota" type="integer" required>
          剩余额度（默认 500,000 额度折合 $1）。
        </ResponseField>
        <ResponseField name="used_quota" type="integer" required>
          已消耗额度。
        </ResponseField>
        <ResponseField name="request_count" type="integer" required>
          用户发起的请求总数。
        </ResponseField>
        <ResponseField name="group" type="string" required>
          用户分组，例如 `default`。
        </ResponseField>
        <ResponseField name="aff_code" type="string" required>
          该用户的邀请码。
        </ResponseField>
        <ResponseField name="aff_count" type="integer" required>
          使用该用户邀请码注册的用户数。
        </ResponseField>
        <ResponseField name="aff_quota" type="integer" required>
          尚可转换的剩余邀请奖励额度。
        </ResponseField>
        <ResponseField name="aff_history_quota" type="integer" required>
          累计邀请奖励额度。
        </ResponseField>
        <ResponseField name="inviter_id" type="integer" required>
          邀请人用户 ID；未使用邀请码注册时为 `0`。
        </ResponseField>
        <ResponseField name="DeletedAt" type="string">
          软删除时间（RFC 3339 格式）；账号未删除时为 `null`。
        </ResponseField>
        <ResponseField name="linux_do_id" type="string" required>
          绑定的 LinuxDO ID；未绑定时为空字符串。
        </ResponseField>
        <ResponseField name="remark" type="string">
          管理员备注，最长 255 字符。为空时不输出。
        </ResponseField>
        <ResponseField name="stripe_customer" type="string" required>
          在线充值使用的 Stripe 客户 ID；未使用时为空字符串。
        </ResponseField>
        <ResponseField name="image_converted_count" type="integer" required>
          多模态适配转换的图片数。
        </ResponseField>
        <ResponseField name="video_converted_count" type="integer" required>
          多模态适配转换的视频数。
        </ResponseField>
        <ResponseField name="created_at" type="integer" required>
          账号创建时间，Unix 秒级时间戳。
        </ResponseField>
        <ResponseField name="last_login_at" type="integer" required>
          最近登录时间，Unix 秒级时间戳；从未登录过为 `0`。
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
软删除的用户在列表中表现为 `DeletedAt` 非 `null`。需要按字段筛选、或只看启用/禁用/已删除用户时，请使用[搜索用户](/cn/nookmux/api/management/user-management/user-search-get)。
</Note>
