## AI 模型接口

AI 模型接口是面向调用方的统一入口，按请求协议分为 OpenAI、Claude、Gemini 三组，外加重排序接口。认证方式与通用约定见 [AI 模型接口总览](/cn/nookmux/api/ai-model/index)。

  </Card>
  <Card icon="message-square" title="Claude 接口" href="/cn/nookmux/api/ai-model/claude/messages">
