---
title: 模型列表
description: 以 Gemini 原生格式列出当前令牌可用的模型。
api: "GET /v1beta/models"
---

以 Gemini 原生格式列出当前令牌可调用的模型，兼容 Google Gemini API 的 `models.list` 方法，供 Gemini 原生客户端在发起生成前发现可用模型。

返回内容为 NookMux 中已配置的模型：包含当前令牌所属分组已启用且已配置价格的模型；若令牌设置了模型限制，则仅返回受限范围内的模型。

## 请求

<RequestExample>

```bash cURL
curl --request GET \
  --url https://your-nookmux-domain/v1beta/models \
  --header 'x-goog-api-key: $NOOKMUX_API_KEY'
```

```python Python
from google import genai

client = genai.Client(
    api_key="$NOOKMUX_API_KEY",
    http_options={"base_url": "https://your-nookmux-domain"},
)

for model in client.models.list():
    print(model.name, "-", model.display_name)
```

</RequestExample>

### 认证

推荐使用 `x-goog-api-key` 请求头传递 NookMux API 令牌（令牌在控制台「令牌」页创建）；网关同时接受 `Authorization: Bearer <token>` 与 `?key=<token>` 查询参数两种兼容写法。

<ParamField path="header.x-goog-api-key" type="string" required>
  NookMux API 令牌，格式为 `x-goog-api-key: <token>`。
</ParamField>

### 请求体

本接口为 GET 请求，无请求体，也不支持 `pageSize`、`page` 等分页查询参数——可用模型一次性全量返回。

### 响应字段

<ResponseField name="models" type="object[]" required>
  模型对象列表。

  <Expandable title="models 结构">
    <ResponseField name="name" type="string" required>
      模型名称，即控制台中配置的模型名（如 `gemini-2.5-pro`），不带官方 API 的 `models/` 前缀；可直接用于其他端点 URL 路径中的 `{model}`。
    </ResponseField>
    <ResponseField name="displayName" type="string" required>
      模型显示名称，当前与 `name` 相同。
    </ResponseField>
    <ResponseField name="baseModelId" type="string">
      基础模型 ID，占位字段，当前实现恒为 `null`。
    </ResponseField>
    <ResponseField name="version" type="string">
      模型版本号，占位字段，当前实现恒为 `null`。
    </ResponseField>
    <ResponseField name="description" type="string">
      模型描述，占位字段，当前实现恒为 `null`。
    </ResponseField>
    <ResponseField name="inputTokenLimit" type="integer">
      输入 token 上限，占位字段，当前实现恒为 `null`。
    </ResponseField>
    <ResponseField name="outputTokenLimit" type="integer">
      输出 token 上限，占位字段，当前实现恒为 `null`。
    </ResponseField>
    <ResponseField name="supportedGenerationMethods" type="string[]">
      支持的生成方法列表，占位字段，当前实现恒为 `null`。
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="nextPageToken" type="string">
  分页游标。当前实现不支持分页，恒为 `null`。
</ResponseField>

<Note>
  需要 OpenAI 格式（`/v1/models` 风格）的模型列表时，请使用「兼容入口汇总」中的 `GET /v1beta/openai/models`，或直接调用 `GET /v1/models`。
</Note>

## 错误码

| HTTP 状态码 | 说明 |
| --- | --- |
| 401 | 令牌无效、已禁用或已过期 |
| 403 | 令牌无权访问，或额度不足 |
| 429 | 触发速率限制 |
| 500 | 服务内部错误 |

错误响应统一为 `{"error": {"message": ..., "type": ...}}` 的 JSON 结构。
