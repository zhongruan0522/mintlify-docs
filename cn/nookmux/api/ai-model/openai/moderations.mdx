---
title: 内容审查
description: 判断文本是否违反内容安全政策，返回各违规类别的标记与置信度评分。
api: "POST /v1/moderations"
---

判断给定文本是否包含违反内容安全政策的内容，返回整体标记与各类别（仇恨、暴力、色情、自残等）的标记与置信度评分。请求与响应格式兼容 OpenAI Moderations API。

NookMux 根据请求中的 `model` 名称将请求分发到对应渠道。审查为同步接口，不支持流式输出，也不产生补全内容；评分阈值由上游模型决定。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url https://your-nookmux-domain/v1/moderations \
  --header 'Authorization: Bearer $NOOKMUX_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "omni-moderation-latest",
  "input": [
    "别让我在论坛上再见到你，否则你会后悔的。",
    "今天的天气很适合出去散步。"
  ]
}'
```

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://your-nookmux-domain/v1",
    api_key="$NOOKMUX_API_KEY",
)

response = client.moderations.create(
    model="omni-moderation-latest",
    input=[
        "别让我在论坛上再见到你，否则你会后悔的。",
        "今天的天气很适合出去散步。",
    ],
)
for i, result in enumerate(response.results):
    print(i, result.flagged, result.category_scores["harassment/threatening"])
```

</RequestExample>

### 认证

<ParamField path="header.Authorization" type="string" required>
  以 `Bearer` 开头的 NookMux API 令牌，格式为 `Authorization: Bearer <token>`。令牌在控制台「令牌」页创建。
</ParamField>

### 请求体

<ParamField path="body.model" type="string">
  审查模型名称，如 `omni-moderation-latest`、`text-moderation-latest`。省略时由 NookMux 填充默认模型；实际可用模型以渠道配置为准，可通过「模型列表」接口获取。
</ParamField>

<ParamField path="body.input" type="string | string[]" required>
  待审查的文本。字符串为单条输入；数组为批量输入，每项对应 `results` 中的一个结果。单次请求最多 32 条、总计不超过 32768 个字符（由上游限制）。
</ParamField>

### 响应字段

<ResponseField name="id" type="string" required>
  本次审查请求的唯一标识。
</ResponseField>

<ResponseField name="model" type="string" required>
  实际使用的审查模型名称。
</ResponseField>

<ResponseField name="results" type="object[]" required>
  审查结果列表，与请求 `input` 中的条目一一对应。

  <Expandable title="results 结构">
    <ResponseField name="flagged" type="boolean">
      整体标记。任一类别评分超过上游阈值时为 `true`。
    </ResponseField>
    <ResponseField name="categories" type="object">
      各违规类别的布尔标记，键为类别名，值为是否超阈值。类别包括 `harassment`、`harassment/threatening`、`hate`、`hate/threatening`、`illicit`、`illicit/violent`、`self-harm`、`self-harm/instructions`、`self-harm/intent`、`sexual`、`sexual/minors`、`violence`、`violence/graphic`（不同模型的类别集合略有差异，以实际响应为准）。
    </ResponseField>
    <ResponseField name="category_scores" type="object">
      各类别的置信度评分，键与 `categories` 一致，取值 `0.0 ~ 1.0`，数值越高表示越可能命中该类别。
    </ResponseField>
  </Expandable>
</ResponseField>

## 错误码

| HTTP 状态码 | 说明 |
| --- | --- |
| 400 | 请求参数错误或模型不支持所请求的能力 |
| 401 | 令牌无效、已禁用或已过期 |
| 403 | 令牌无权访问该模型，或额度不足 |
| 429 | 触发速率限制 |
| 500 | 上游渠道返回错误，`error.message` 中包含上游错误详情 |
