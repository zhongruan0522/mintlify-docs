---
title: 对话补全
description: 基于对话历史创建模型响应，支持流式输出、工具调用与多模态输入。
api: "POST /v1/chat/completions"
---

根据对话历史创建模型响应。支持流式与非流式响应，请求与响应格式兼容 OpenAI Chat Completions API。

NookMux 根据请求中的 `model` 名称将请求分发到对应渠道，并以统一的 OpenAI 格式返回响应；`model` 可以是任意已配置的模型名（OpenAI、Claude、Gemini、通义千问等，由控制台「渠道 → 模型」决定）。

## 请求

<RequestExample>

```bash cURL
curl --request POST \
  --url https://your-nookmux-domain/v1/chat/completions \
  --header 'Authorization: Bearer $NOOKMUX_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "gpt-4o",
  "messages": [
    { "role": "system", "content": "你是编程助手，擅长写简洁高效的代码。" },
    { "role": "user", "content": "写一个 Python 函数，计算斐波那契数列第 n 项。" }
  ],
  "stream": false
}'
```

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="https://your-nookmux-domain/v1",
    api_key="$NOOKMUX_API_KEY",
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "system", "content": "你是编程助手，擅长写简洁高效的代码。"},
        {"role": "user", "content": "写一个 Python 函数，计算斐波那契数列第 n 项。"},
    ],
)
print(response.choices[0].message.content)
```

</RequestExample>

### 认证

<ParamField path="header.Authorization" type="string" required>
  以 `Bearer` 开头的 NookMux API 令牌，格式为 `Authorization: Bearer <token>`。令牌在控制台「令牌」页创建。
</ParamField>

### 请求体

<ParamField path="body.model" type="string" required>
  要调用的模型名称。取值为 NookMux 中已配置的模型，可通过「模型列表」接口获取可用模型。
</ParamField>

<ParamField path="body.messages" type="object[]" required>
  对话消息列表，按时间顺序排列。每条消息包含 `role` 与 `content`，详细结构见下表。

  <Expandable title="messages 结构">
    <ParamField path="role" type="string" required>
      消息角色：`system`（设定助手行为）、`user`（用户输入）、`assistant`（助手回复）、`tool`（工具调用结果）。
    </ParamField>
    <ParamField path="content" type="string | object[]" required>
      消息内容。纯文本时为字符串；多模态输入时为内容块数组，`type` 可取 `text`、`image_url`、`input_audio`、`file`、`video_url`。
    </ParamField>
    <ParamField path="content[].image_url.url" type="string">
      图像的 URL 或 Base64 编码数据（`data:image/jpeg;base64,...` 格式）。
    </ParamField>
    <ParamField path="content[].image_url.detail" type="string" default="high">
      图像识别精度：`high`（高精度，消耗更多 token）或 `low`（低精度）。
    </ParamField>
    <ParamField path="content[].input_audio.data" type="string">
      音频的 Base64 编码数据。
    </ParamField>
    <ParamField path="content[].input_audio.format" type="string">
      音频格式：`wav` 或 `mp3`。
    </ParamField>
    <ParamField path="name" type="string">
      参与者的可选标识名称，用于区分同角色的不同参与者。
    </ParamField>
    <ParamField path="tool_calls" type="object[]">
      助手消息携带的工具调用列表，每个元素含 `id`、`type`、`function`（`name`、`arguments`）。
    </ParamField>
    <ParamField path="tool_call_id" type="string">
      `role` 为 `tool` 时必填，对应的工具调用 ID。
    </ParamField>
    <ParamField path="reasoning_content" type="string">
      思维链内容。用于回传上一轮推理模型的思考过程（DeepSeek-R1 等模型）。
    </ParamField>
    <ParamField path="prefix" type="boolean">
      是否将本条消息内容作为模型续写的前缀（部分模型支持，如 DeepSeek）。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="body.stream" type="boolean" default="false">
  是否启用流式输出。`true` 时通过 Server-Sent Events 分块返回生成内容，结束时会返回 `data: [DONE]`。
</ParamField>

<ParamField path="body.stream_options" type="object">
  流式输出选项。

  <Expandable title="stream_options 结构">
    <ParamField path="include_usage" type="boolean" default="false">
      流式输出的最后一个 chunk 是否携带 `usage` 统计字段。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="body.max_tokens" type="integer">
  生成的最大 token 数量（含可见输出与思维链）。达到上限时输出会被截断（`finish_reason` 为 `length`）。
</ParamField>

<ParamField path="body.max_completion_tokens" type="integer">
  与 `max_tokens` 等价的新字段名，面向新一代推理模型（o 系列、gpt-5 等）。同时传入时以较大者为准。
</ParamField>

<ParamField path="body.reasoning_effort" type="string">
  推理模型的思考深度：`minimal`、`low`、`medium`、`high`。仅对支持推理的模型有效。
</ParamField>

<ParamField path="body.verbosity" type="string">
  gpt-5 系列支持的输出详细程度：`low` 或 `high`。
</ParamField>

<ParamField path="body.temperature" type="number">
  采样温度，取值 `0.0 ~ 2.0`。较高的值使输出更随机、更具创造性；较低的值使输出更稳定。建议调整 `temperature` 或 `top_p` 其中之一。
</ParamField>

<ParamField path="body.top_p" type="number">
  核采样参数。模型仅考虑累积概率达到 `top_p` 的候选词，如 `0.1` 表示只考虑前 10% 概率的词。
</ParamField>

<ParamField path="body.top_k" type="integer">
  每步仅从概率最高的 k 个候选词中采样（部分模型支持，如 Gemini）。
</ParamField>

<ParamField path="body.n" type="integer" default="1">
  为每条输入消息生成的回复数量。
</ParamField>

<ParamField path="body.stop" type="string | string[]">
  最多 4 个停止序列。模型生成包含任一序列的文本时停止输出，序列本身不包含在输出中。
</ParamField>

<ParamField path="body.frequency_penalty" type="number">
  频率惩罚，`-2.0 ~ 2.0`。正值根据已有词的出现频率降低其重复概率。
</ParamField>

<ParamField path="body.presence_penalty" type="number">
  存在惩罚，`-2.0 ~ 2.0`。正值根据词是否已出现降低其再次出现的概率。
</ParamField>

<ParamField path="body.seed" type="integer">
  采样随机种子。相同种子与参数下尽量输出可复现的结果。
</ParamField>

<ParamField path="body.response_format" type="object">
  指定输出格式。

  <Expandable title="response_format 结构">
    <ParamField path="type" type="string" default="text">
      输出格式：`text`（默认，纯文本）、`json_object`（JSON 对象）、`json_schema`（按 JSON Schema 输出）。
    </ParamField>
    <ParamField path="json_schema" type="object">
      `type` 为 `json_schema` 时的结构定义，含 `name`（必填）、`description`、`schema`、`strict`。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="body.tools" type="object[]">
  模型可调用的工具列表。

  <Expandable title="tools 结构">
    <ParamField path="type" type="string" required>
      工具类型，目前支持 `function`。
    </ParamField>
    <ParamField path="function.name" type="string" required>
      函数名。须符合 `^[a-zA-Z0-9_-]{1,64}$`。
    </ParamField>
    <ParamField path="function.description" type="string">
      函数功能描述，模型据此决定何时调用。
    </ParamField>
    <ParamField path="function.parameters" type="object">
      函数参数的 JSON Schema 对象，`type` 固定为 `object`。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="body.tool_choice" type="string | object">
  控制模型如何选择工具：`none`（禁用）、`auto`（默认，由模型决定）、`required`（强制调用），或指定具体函数 `{"type": "function", "function": {"name": "my_func"}}`。
</ParamField>

<ParamField path="body.parallel_tool_calls" type="boolean">
  是否允许模型在一次回复中并行发起多个工具调用。
</ParamField>

<ParamField path="body.logprobs" type="boolean">
  是否返回输出 token 的对数概率。
</ParamField>

<ParamField path="body.top_logprobs" type="integer">
  每个输出位置返回概率最高的 n 个 token（0 ~ 20）。设置 `logprobs` 时生效。
</ParamField>

<ParamField path="body.logit_bias" type="object">
  修改指定 token 在采样中的出现概率，键为 token ID，值为 `-100 ~ 100`。
</ParamField>

<ParamField path="body.modalities" type="string[]">
  请求的输出模态：`text`、`audio`。
</ParamField>

<ParamField path="body.audio" type="object">
  音频输出参数：`voice`（音色）、`format`（`wav` 或 `mp3`）。
</ParamField>

<ParamField path="body.user" type="string">
  终端用户标识符，用于 NookMux 识别与滥用监测。
</ParamField>

<ParamField path="body.metadata" type="object">
  附加的键值对元数据，最多 16 组。
</ParamField>

<ParamField path="body.store" type="boolean">
  是否存储本次请求的输出（供模型蒸馏与评测产品使用，仅 OpenAI 渠道有效）。
</ParamField>

<ParamField path="body.prediction" type="object">
  预测输出。提供期望内容的近似文本可加速生成。
</ParamField>

<ParamField path="body.prompt_cache_key" type="string">
  缓存键。用于提高提示词缓存命中率。
</ParamField>

<ParamField path="body.web_search_options" type="object">
  Claude 渠道的网页搜索选项：`search_context_size`（`low` / `medium` / `high`）与 `user_location`。
</ParamField>

<ParamField path="body.search_parameters" type="object">
  Perplexity 等渠道的搜索参数（`search_domain_filter`、`search_recency_filter`、`return_images` 等）。
</ParamField>

<ParamField path="body.reasoning" type="object">
  OpenRouter 风格推理参数：`effort`、`max_tokens`。
</ParamField>

<ParamField path="body.thinking" type="object">
  思维链开关（GLM-4.5 及以上 / Claude 等渠道），结构如 `{"type": "enabled", "budget_tokens": 1024}`。
</ParamField>

<ParamField path="body.enable_thinking" type="boolean">
  通义千问 Qwen3 系列的思维链开关。
</ParamField>

<ParamField path="body.extra_body" type="object">
  Gemini 渠道的扩展参数，原样透传给上游。
</ParamField>

<ParamField path="body.think" type="object">
  Ollama 渠道的思考参数。
</ParamField>

<Note>
  各厂商透传字段（`thinking`、`enable_thinking`、`extra_body`、`web_search_options` 等）仅在对应渠道生效，其余渠道会按参数过滤规则丢弃；字段能否透传还取决于控制台「模型 → 参数覆盖」的配置。
</Note>

## 响应

<ResponseExample>

```json 200
{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1735689600,
  "model": "gpt-4o",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "def fibonacci(n):\n    if n <= 1:\n        return n\n    a, b = 0, 1\n    for _ in range(n - 1):\n        a, b = b, a + b\n    return a"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 42,
    "completion_tokens": 68,
    "total_tokens": 110
  }
}
```

</ResponseExample>

### 响应字段

<ResponseField name="id" type="string" required>
  本次补全的唯一标识。
</ResponseField>

<ResponseField name="object" type="string" required>
  对象类型，固定为 `chat.completion`。
</ResponseField>

<ResponseField name="created" type="integer" required>
  响应创建时间的 Unix 时间戳（秒）。
</ResponseField>

<ResponseField name="model" type="string" required>
  生成本次响应的模型名称。
</ResponseField>

<ResponseField name="choices" type="object[]" required>
  模型回复列表，长度等于请求中的 `n`。

  <Expandable title="choices 结构">
    <ResponseField name="index" type="integer">
      该条回复在列表中的序号。
    </ResponseField>
    <ResponseField name="message" type="object">
      回复消息对象。

      <Expandable title="message 结构">
        <ResponseField name="role" type="string">
          固定为 `assistant`。
        </ResponseField>
        <ResponseField name="content" type="string">
          回复文本内容。模型调用工具时为 `null`。
        </ResponseField>
        <ResponseField name="reasoning_content" type="string">
          思维链内容（推理模型返回，如 DeepSeek-R1）。
        </ResponseField>
        <ResponseField name="tool_calls" type="object[]">
          模型发起的工具调用列表，每个元素含 `id`（调用 ID）、`type`（固定 `function`）、`function.name`、`function.arguments`（JSON 字符串形式的参数）。
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="finish_reason" type="string">
      生成结束原因：`stop`（自然结束或命中停止序列）、`length`（达到 max_tokens 上限）、`tool_calls`（模型请求调用工具）、`content_filter`（内容被安全策略拦截）。
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="usage" type="object" required>
  Token 使用统计。

  <Expandable title="usage 结构">
    <ResponseField name="prompt_tokens" type="integer">
      输入消耗的 token 数。
    </ResponseField>
    <ResponseField name="completion_tokens" type="integer">
      输出消耗的 token 数。
    </ResponseField>
    <ResponseField name="total_tokens" type="integer">
      总消耗 token 数。
    </ResponseField>
    <ResponseField name="prompt_tokens_details" type="object">
      输入明细，含 `cached_tokens`（命中缓存的 token 数）。
    </ResponseField>
    <ResponseField name="completion_tokens_details" type="object">
      输出明细，含 `reasoning_tokens`（思维链 token 数）。
    </ResponseField>
  </Expandable>
</ResponseField>

## 流式响应

设置 `"stream": true` 后，响应以 `text/event-stream` 返回，每个 `data:` 行为一个 chunk：

```json
data: {"id":"chatcmpl-abc123","object":"chat.completion.chunk","created":1735689600,"model":"gpt-4o","choices":[{"index":0,"delta":{"role":"assistant"},"finish_reason":null}]}

data: {"id":"chatcmpl-abc123","object":"chat.completion.chunk","created":1735689600,"model":"gpt-4o","choices":[{"index":0,"delta":{"content":"def"},"finish_reason":null}]}

data: {"id":"chatcmpl-abc123","object":"chat.completion.chunk","created":1735689600,"model":"gpt-4o","choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}

data: [DONE]
```

<ResponseField name="delta" type="object">
  增量内容。首个 chunk 携带 `role`；后续 chunk 通过 `content` 增量返回文本，`reasoning_content` 增量返回思维链，`tool_calls` 增量返回工具调用片段。
</ResponseField>

<Note>
  请求中设置 `stream_options.include_usage: true` 时，最后一个 chunk（`finish_reason` 之后）会额外携带 `usage` 字段，且 `choices` 为空数组。
</Note>

## 错误码

| HTTP 状态码 | 说明 |
| --- | --- |
| 400 | 请求参数错误或模型不支持所请求的能力 |
| 401 | 令牌无效、已禁用或已过期 |
| 403 | 令牌无权访问该模型，或额度不足 |
| 429 | 触发速率限制 |
| 500 | 上游渠道返回错误，`error.message` 中包含上游错误详情 |
