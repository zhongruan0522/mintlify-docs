---
title: 宝塔面板部署
---

本文档提供使用宝塔面板 Docker 功能部署 NookMux 的步骤。

## 前置要求

- 宝塔面板 9.2.0 或更高版本。
- 已在面板中安装 Docker 服务。
- 服务器已放行 `3000` 或您计划映射的外部端口。

## 创建容器

1. 登录宝塔面板，进入 **Docker**。
2. 首次进入时按提示安装 Docker 服务。
3. 进入 **镜像管理**，拉取镜像：

   ```text
   ghcr.io/nookmux/nookmux:latest
   ```

4. 进入 **容器列表**，点击创建容器。
5. 填写容器参数：

| 配置项 | 建议值 |
| --- | --- |
| 容器名称 | `nookmux` |
| 镜像 | `ghcr.io/nookmux/nookmux:latest` |
| 端口映射 | `3000:3000` |
| 目录映射 | `/your/host/data:/data`、`/your/host/logs:/app/logs` |
| 启动命令 | `--log-dir /app/logs` |
| 环境变量 | `TZ=Asia/Shanghai`、`SESSION_SECRET=...`、`CRYPTO_SECRET=...` |

<Card type="warning" title="生产环境安全配置">
  `SESSION_SECRET` 和 `CRYPTO_SECRET` 应使用不同的随机字符串。不要使用示例值或公开泄露的字符串。
</Card>

## 可选数据库与 Redis

默认不设置 `SQL_DSN` 时使用 SQLite，数据库文件在 `/data/one-api.db`。如果使用外部数据库或 Redis，可添加：

```text
SQL_DSN=mysql://user:password@db-host:3306/nookmux
REDIS_CONN_STRING=redis://:password@redis-host:6379
```

PostgreSQL 示例：

```text
SQL_DSN=postgres://user:password@db-host:5432/nookmux
```

openGauss 示例（目标库需以 `DBCOMPATIBILITY='PG'` 创建）：

```text
SQL_DSN=opengauss://user:password@db-host:5432/nookmux
```

达梦 DM8 示例（实例需以 `CASE_SENSITIVE=N` 初始化，账号需 `SELECT ANY DICTIONARY` 权限；口令按字面值写入，不得包含 `:` 和 `?`）：

```text
SQL_DSN=dm://user:password@db-host:5236?schema=NOOKMUX
```

金仓 KingbaseES 示例（Oracle 兼容模式；实例不得开启 `enable_ci`，否则启动时被拒绝；口令按 URL 规则 percent-encode）：

```text
SQL_DSN=kingbase://user:password@db-host:54321/nookmux?sslmode=disable
```

生产环境容量建议：

- 金仓默认 `max_connections=100`。主库与日志库各持有独立连接池、默认上限各为 1000（`SQL_MAX_OPEN_CONNS`），请按实例会话上限显著调低（如 `SQL_MAX_OPEN_CONNS=50`），否则高峰期新连接将以 `FATAL 53300: sorry, too many clients already` 失败。
- 未开启 SSL 的实例须在 DSN 中保留 `sslmode=disable`：Gokb 驱动默认 `require` 且无明文回退。
- Gokb 默认路径每条带参 SQL 需两次往返且无语句缓存，生产负载建议开启 `SQL_PREPARE_STMT=true`。

## 访问系统

容器启动后访问：

```text
http://服务器IP:3000
```

首次访问会进入初始化页面。完成管理员账号创建后即可登录。

## 常见问题

### 无法访问界面

- 检查端口映射是否正确。
- 确认服务器防火墙和云安全组已放行端口。
- 查看容器日志确认服务是否启动成功。

### 数据丢失

- 确认已正确映射 `/data`。
- 确认主机目录权限允许容器读写。
