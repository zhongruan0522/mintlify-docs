title: CC Switch - AI 编程工具供应商切换工具
---

<Info>
  CC Switch 是一款开源的桌面工具，用于统一管理 Claude Code、Claude Desktop、Codex、Gemini CLI、OpenCode 等 AI 编程工具的 API 供应商，切换供应商无需手动修改配置文件。NookMux 控制台的「密钥」页面内置了 CC Switch 一键导入入口，可把当前令牌和站点地址直接写入 CC Switch。
</Info>

- 官方网站：[https://ccswitch.io](https://ccswitch.io)
- 项目地址：[https://github.com/farion1231/cc-switch](https://github.com/farion1231/cc-switch)
- 深度链接协议说明：[https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/zh/5-faq/5.3-deeplink.md](https://github.com/farion1231/cc-switch/blob/main/docs/user-manual/zh/5-faq/5.3-deeplink.md)

## 从 NookMux 一键导入

1. 确保本机已安装并至少运行过一次 CC Switch（安装时会注册 `ccswitch://` 协议）。
2. 在 NookMux 控制台「密钥」页面，找到要使用的令牌，打开行操作菜单，点击 **CC Switch**。
3. 在弹出的对话框中选择应用类型（Claude / Codex / Gemini），填写配置名称并选择主模型；Claude 还可按需填写 Haiku / Sonnet / Opus 模型。
4. 点击 **打开 CC Switch**，浏览器会唤起 CC Switch 并弹出导入确认对话框，其中已填入：

   | 字段 | 内容 |
   | --- | --- |
   | endpoint | Claude / Gemini 为站点根地址；Codex 为站点地址 + `/v1` |
   | apiKey | 当前令牌对应的完整密钥（以 API Key 前缀开头，默认 `sk-`） |
   | model | 所选的主模型；Claude 另含 haikuModel / sonnetModel / opusModel |

5. 核对后确认导入。确认框里的「导入后立即切换」开关决定是否立即切换到该供应商。
6. 在 CC Switch 中启用或切换供应商后即生效：Claude Code 无需重启；Codex、Gemini CLI 需重启终端或 CLI。

一键导入使用的是 CC Switch 的深度链接协议：`ccswitch://v1/import?resource=provider&app=...`。

## 说明

- 深链接里带有令牌的完整密钥，只在可信设备上打开，不要转发给他人。
- 如果浏览器没有弹出 CC Switch，请确认已安装客户端并允许浏览器打开外部应用。
- 除一键导入外，也可以在 CC Switch 中手动添加供应商：Claude 类型填站点根地址，Codex 类型填 `https://your-domain.com/v1`，密钥使用 NookMux 令牌。
