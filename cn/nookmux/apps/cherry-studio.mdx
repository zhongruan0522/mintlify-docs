## 接入方法

Cherry Studio 内置了 New API 提供商，填一次地址即可同时使用 OpenAI Chat、OpenAI Responses、Anthropic Messages 和 Gemini 协议，这四种协议 NookMux 都支持。

### 参数填写

| 配置项 | 填写内容 |
| --- | --- |
| 提供商 | New API（内置），或「添加自定义提供商」 |
| API 密钥 | NookMux 令牌（以 API Key 前缀开头，默认 `sk-`），在「密钥」页面创建并复制 |
| API 地址 | `https://your-domain.com`，填站点根地址。Cherry Studio 会按所用协议自动补上版本号和路径（如 `/v1`、`/v1beta`），不要填到 `/chat/completions` 这样的完整路径 |
| 模型 | 点「获取模型列表」后勾选，或手动添加 |

### 配置步骤

1. 在 NookMux 控制台「密钥」页面创建令牌并复制 API Key。
2. 打开 Cherry Studio 的【设置】→【模型服务】，在服务商列表中启用【New API】；也可以点「+ 添加服务商」→「添加自定义提供商」。
3. 「API 密钥」粘贴 NookMux 令牌，「API 地址」填 `https://your-domain.com`。
4. 点「检测」确认连通，再点「获取模型列表」拉取并勾选要使用的模型；手动添加时，模型名称需与 NookMux 渠道中配置的模型名一致。
5. 返回聊天页面，选择刚添加的模型开始对话。

## 画图

如果渠道中配置了图像生成模型（如 DALL·E、Gemini 图像模型等），在 Cherry Studio 的【绘画】页面选择对应模型，并在【设置】→【默认模型】→【绘画模型】中设为默认。使用自定义提供商时，还需要在该提供商的「端点设置」中填写「图像生成 Base URL」。

## 更多用法

知识库、智能助手等功能的模型配置方式相同，均可指向同一个 NookMux 提供商。详细用法请参考 [Cherry Studio 官方文档](https://cherryai.com.cn/docs/zh-cn)。
