<Info>
  LunaTranslator 是一款开源免费的视觉小说（GalGame）翻译器，支持 HOOK 提取文本、OCR、离线翻译和大模型翻译，可通过「大模型通用接口」接入 OpenAI 兼容服务。
</Info>

- 项目地址：[https://github.com/HIllya51/LunaTranslator](https://github.com/HIllya51/LunaTranslator)
- 项目文档：[软件下载 & 常见问题](https://docs.lunatranslator.org/zh/README.html)
- 大模型翻译接口：[https://docs.lunatranslator.org/zh/guochandamoxing.html](https://docs.lunatranslator.org/zh/guochandamoxing.html)

## 功能支持

- **HOOK**：提取游戏文本，适配绝大多数视觉小说
- **内嵌翻译**：部分游戏支持将译文内嵌到游戏中
- **OCR**：内置离线 OCR，并支持多种在线 OCR 引擎
- **大模型翻译**：支持 OpenAI 兼容接口作为翻译引擎
- **语言学习**：日语分词、假名注音、AnkiConnect、Yomitan
- **语音合成 / 语音识别**：支持多种在线和离线方案

## 安装

在 [LunaTranslator 文档 - 软件下载 & 常见问题](https://docs.lunatranslator.org/zh/README.html) 下载安装。

## 在 LunaTranslator 中接入 NookMux

LunaTranslator 的「大模型通用接口」使用 OpenAI 兼容协议，可直接指向 NookMux。

### 配置步骤

1. 在 NookMux 控制台「密钥」页面创建令牌并复制 API Key（以 API Key 前缀开头，默认 `sk-`）。
2. 打开 LunaTranslator →「设置」→「翻译设置」，在大模型接口区域点击上方的「+」按钮，选择「大模型通用接口」，在弹出的窗口中为新接口命名。
3. 启用复制出的新接口，点击它的参数设置按钮，填写：

   | 配置项 | 内容 |
   | --- | --- |
   | API接口地址 | NookMux 站点地址 + `/v1`，例如 `https://your-domain.com/v1`；程序会自动请求 `<地址>/chat/completions` |
   | API Key | NookMux 令牌 |
   | model | 点击下拉框旁的刷新按钮拉取模型列表，或直接输入模型名 |

4. 点击「确定」保存。

打开该接口旁的开关即可启用接口。更多用法请查看 LunaTranslator 官方文档：[大模型翻译接口](https://docs.lunatranslator.org/zh/guochandamoxing.html)。
