## 接入 NookMux

LangBot 支持接入本地部署或线上的 NookMux。LangBot 预置了名为 New API 的供应商类型，通过 OpenAI 兼容接口调用 NookMux。

### 接入对话模型

1. 在 NookMux 控制台「密钥」页面创建令牌并复制（以 API Key 前缀开头，默认 `sk-`）。NookMux 的接口地址是站点地址 + `/v1`：本地部署为 `http://127.0.0.1:3000/v1`，线上为 `https://your-domain.com/v1`。LangBot 运行在 Docker 中时，`127.0.0.1` 指向容器自身，需要改用宿主机 IP 或容器网络内可达的地址（可参考官方文档[「网络配置详解」](https://langbot.app/docs/zh/workshop/network-details/)）。
2. 打开 LangBot WebUI，点击右上角的账户菜单，进入「系统设置」→「模型配置」。
3. 点击「添加供应商」：「供应商名称」填 `NookMux`；「供应商类型」在「中转平台」分组中选择 `New API`；「请求URL」填第 1 步的接口地址；「API Key」填 NookMux 令牌；点击「保存」。
4. 在该供应商卡片上点击「扫描模型」，勾选要使用的模型后点击「添加所选模型」。也可以点击「添加」→「手动添加」，在「添加对话模型」表单中填写「模型名称」（NookMux 中的模型 ID），按需勾选「视觉能力」「函数调用」等能力后保存。
5. 在左侧进入「处理器」，选中要使用的流水线，在「AI 能力」页把运行器设为「内置 Agent」，「模型」选择刚添加的模型，保存。
6. 在流水线详情页的调试面板中选择「私聊」或「群聊」并发送消息验证，也可以直接与绑定该流水线的机器人对话。部署机器人请参考官方文档「机器人（Bots）」。

### 在知识库中使用 NookMux 嵌入模型

LangBot 的知识库可以使用 NookMux 提供的嵌入模型。

1. 在「系统设置」→「模型配置」中，点击 NookMux 供应商卡片上的「添加」→「添加嵌入模型」，「模型名称」填 NookMux 中的嵌入模型 ID，保存。
2. 在左侧进入「知识库」，点击「创建知识库」：填写知识库名称，选择一个 RAG 引擎（由已安装的插件提供），在引擎的配置表单中把嵌入模型设为刚添加的模型，设置分块大小等参数后点击「创建」。
3. 如果所选 RAG 引擎支持文档上传，在知识库的「文档」页上传文档，等待索引完成。
4. 回到流水线的「AI 能力」页，保持运行器为「内置 Agent」，在下方选择刚创建的知识库。

之后即可在「对话调试」或绑定该流水线的机器人上使用知识库对话。模型与知识库的更多用法请查看 [LangBot 官方文档](https://docs.langbot.app/)。
