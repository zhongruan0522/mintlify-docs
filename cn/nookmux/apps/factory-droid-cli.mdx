## 安装

macOS / Linux：

```bash
curl -fsSL https://app.factory.ai/cli | sh
```

Windows（PowerShell）：

```powershell
irm https://app.factory.ai/cli/windows | iex
```

npm（需要 Node.js 20 及以上）：

```bash
npm install -g droid
```

```bash
# 验证安装
droid --version
```

macOS / Linux 的脚本把 `droid` 安装到 `~/.local/bin`，按提示把该目录加入 PATH；Linux 需要系统已安装 `xdg-utils`。Windows 脚本把 `droid.exe` 安装到 `%USERPROFILE%\bin` 并自动加入用户 PATH。首次启动 `droid` 时如提示登录，按提示在浏览器完成 Factory 账号登录（免费）。

## 接入 NookMux

Droid CLI 通过 `~/.factory/settings.json`（Windows 为 `%USERPROFILE%\.factory\settings.json`）的 `customModels` 数组配置自定义模型。NookMux 提供 OpenAI 兼容接口，示例如下：

```json
{
  "customModels": [
    {
      "model": "gpt-5.6",
      "displayName": "NookMux GPT",
      "baseUrl": "https://your-domain.com/v1",
      "apiKey": "${NOOKMUX_API_KEY}",
      "provider": "generic-chat-completion-api",
      "maxOutputTokens": 16384
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `model` | 必填。与 NookMux 渠道中配置的模型名一致 |
| `provider` | 必填。接口协议，取值见下 |
| `baseUrl` | 必填。NookMux 站点地址 + `/v1`；`provider` 为 `anthropic` 时填站点根地址 |
| `displayName` | `/model` 列表中显示的名称 |
| `apiKey` | 支持 `${VAR_NAME}` 语法引用环境变量 |
| `maxOutputTokens` / `maxContextLimit` | 可选。最大输出 token 数与模型上下文窗口（输入 token 数），按模型实际能力填写 |

`provider` 的取值：

- `generic-chat-completion-api`：OpenAI Chat Completions 兼容（大多数场景用这个）。
- `openai`：OpenAI Responses API。
- `anthropic`：Anthropic Messages API，`baseUrl` 填 NookMux 站点根地址，`model` 用 `claude-*` 系列。

Anthropic 模型示例：

```json
{
  "customModels": [
    {
      "model": "claude-sonnet-4-5-20250929",
      "displayName": "NookMux Claude",
      "baseUrl": "https://your-domain.com",
      "apiKey": "${NOOKMUX_API_KEY}",
      "provider": "anthropic",
      "maxOutputTokens": 16384
    }
  ]
}
```

## 使用

1. 在 NookMux 控制台「密钥」页面创建令牌并复制完整密钥（以 API Key 前缀开头，默认 `sk-`）。
2. 导出环境变量：

   ```bash
   export NOOKMUX_API_KEY=sk-your-nookmux-token
   ```

3. 启动 Droid CLI：

   ```bash
   cd /path/to/your/project
   droid
   ```

4. 使用 `/model` 命令，在「Custom Models」分组中选择刚配置的模型。也可以在 `/settings` 的 Custom models 中添加和管理自定义模型。

## 常见问题

### 模型未出现在选择器中

- 检查 `~/.factory/settings.json` 是否为合法 JSON。
- 确认 `model`、`provider`、`baseUrl` 等必填字段完整。

### 认证失败

- 确认环境变量已导出且与 `apiKey` 中的 `${...}` 引用名一致。
- 确认令牌是以 API Key 前缀开头（默认 `sk-`）的完整 NookMux 密钥且未被禁用。

### PowerShell 执行策略限制

改为下载脚本后，仅对这一次运行绕过执行策略：

```powershell
curl.exe -fsSL https://app.factory.ai/cli/windows -o install.ps1
powershell -ExecutionPolicy Bypass -File install.ps1
del install.ps1
```
