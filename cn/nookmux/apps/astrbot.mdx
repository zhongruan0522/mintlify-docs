<Info>
  AstrBot 是一个开源的一站式 Agent 聊天机器人平台，可将大模型能力接入 QQ、飞书、钉钉、企业微信等主流即时通讯软件，为个人、开发者和团队提供可靠、可扩展的对话式智能基础设施。

## 接入方法

AstrBot 通过 OpenAI 兼容的 Chat Completions 接口接入 NookMux。

### 配置步骤

#### 获取 NookMux API Key

在 NookMux 注册并登录后，进入控制台「密钥」页面，创建一个新的令牌并复制生成的 API Key（以 API Key 前缀开头，默认 `sk-`）。

#### 在 AstrBot 中添加模型提供商

1. 打开 AstrBot 管理面板，进入「模型提供商」的「对话」页签，点击「新增」。
2. 在模板列表中选择 `OpenAI Compatible`。
3. 填写提供商名称、「API Key」（NookMux 令牌）和「Base URL」（官方文档中称为 API Base URL）：
   - AstrBot 与 NookMux 在同一台机器上且都不是容器部署：`http://localhost:3000/v1`
   - 线上部署：`https://your-domain.com/v1`

   AstrBot 运行在 Docker 中时，`localhost` 指向容器自身，需要改用宿主机地址：Docker Desktop（Mac / Windows）为 `http://host.docker.internal:3000/v1`，Linux 为 `http://<docker0 网关 IP>:3000/v1`（默认 `172.17.0.1`），可参考官方的 [Docker 部署文档](https://docs.astrbot.app/deploy/astrbot/docker.html)。

4. 点击「保存并获取模型」，在可用模型列表中找到要使用的模型，点击右侧 `+` 添加，并确认模型已启用。获取不到模型列表时，先点「保存配置」，再点「自定义模型」手动填写模型 ID；可以用「测试模型」检查连通性。

#### 设置对话模型

进入「配置文件」，选择要使用的配置文件，在「AI」→「模型」中把「对话模型」设为刚添加的模型，点击右下角「保存配置」。

至此，AstrBot 会通过 NookMux 调用渠道中配置的各种 AI 模型。
