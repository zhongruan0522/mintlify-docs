## 集成指南

大多数应用只需要配置以下信息即可连接 NookMux：

1. **API 地址**：您的 NookMux 服务地址。三种兼容接口的基础地址不同，各应用拼接路径的方式也不同，具体填法以各应用页面的说明为准：OpenAI 兼容接口为 `https://your-domain.com/v1`；Claude 兼容接口的完整地址是 `https://your-domain.com/v1/messages`（例如 Claude Code 的 `ANTHROPIC_BASE_URL` 只填站点根地址）；Gemini 兼容接口为 `https://your-domain.com/v1beta`。
2. **API Key**：在 NookMux 控制台「密钥」页面创建并复制的令牌，以 API Key 前缀开头（默认 `sk-`，管理员可在「系统设置」→「站点与品牌」→「系统信息」中自定义）。
3. **模型名称**：选择渠道中已配置的模型。

具体配置步骤请参考各应用的详细文档。
