## 核心特性

- **多会话聊天**：多会话独立上下文，对话数据保存在本地
- **多模型支持**：支持 OpenAI、Claude、Gemini、Qwen 等主流模型，以及 Ollama、LM Studio 等本地模型
- **多代理模式**：可同时运行多个 AI 代理，通过 MCP 统一管理
- **文件管理**：文件树浏览、拖拽上传、AI 智能整理
- **预览面板**：支持 PDF、Office、代码、Markdown、图片等多种格式预览和实时编辑
- **多渠道访问**：WebUI 远程访问、Telegram 集成、飞书集成

## 接入方法

AionUi 通过 OpenAI 兼容接口接入 NookMux。

### 参数填写

| 配置项 | 填写内容 |
| --- | --- |
| 模型平台 | New API（或「自定义」） |
| API 请求地址 | `https://your-domain.com/v1`（需带 `/v1`，AionUi 会在其后拼接 `/chat/completions`） |
| API Key | NookMux 令牌（以 API Key 前缀开头，默认 `sk-`），在「密钥」页面创建并复制 |
| 模型名称 | 与 NookMux 渠道中配置的一致的模型 ID |
| 请求协议 | OpenAI（仅 New API 平台显示） |

### 配置步骤

1. **打开模型设置**：进入「设置」→「模型」，点击「添加模型」。
2. **选择模型平台**：选「New API」（或「自定义」）。
3. **配置 API 信息**：「API 请求地址」填 `https://your-domain.com/v1`，「API Key」粘贴 NookMux 令牌，「完整 URL」保持关闭。
4. **添加模型**：在「模型名称」里点搜索图标拉取模型列表，或直接输入模型名称（可多选）。
5. **请求协议**：模型平台为 New API 时，把「请求协议」设为「OpenAI」。以 `claude`、`gemini` 开头的模型名会被自动判为其他协议，需要手动改回。
6. **开始使用**：保存后，点击该模型行的「健康检测」图标确认连通。自定义模型目前仅 Aion CLI 代理可用，其他 Agent 使用各自内置的模型。
