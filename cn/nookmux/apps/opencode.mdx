<Info>
  OpenCode 是一款开源的编码 Agent，提供终端界面、桌面应用和 Web 界面，内置多家模型提供商的目录，也可以通过配置文件接入自定义的模型服务。
</Info>

- 官方网站：[https://opencode.ai](https://opencode.ai)
- 官方文档：[https://opencode.ai/docs](https://opencode.ai/docs)
- GitHub 仓库：[https://github.com/anomalyco/opencode](https://github.com/anomalyco/opencode)
- 提供商配置：[https://opencode.ai/docs/providers](https://opencode.ai/docs/providers)

## 安装

macOS / Linux：

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

Homebrew：

```bash
brew install anomalyco/tap/opencode-v2
```

npm：

```bash
npm install -g @opencode/cli
```

Windows 不支持通过包管理器安装，请在[官方文档](https://opencode.ai/docs)下载对应平台的独立可执行文件。

## 接入 NookMux

OpenCode 的配置文件是 `opencode.json` 或 `opencode.jsonc`：全局配置放在 `~/.config/opencode/opencode.jsonc`，也可以放在项目根目录或项目的 `.opencode/` 目录下。在 `providers` 中添加一个自定义提供商：

```jsonc title="~/.config/opencode/opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "nookmux": {
      "name": "NookMux",
      "env": ["NOOKMUX_API_KEY"],
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "https://your-domain.com/v1"
      },
      "models": {
        "gpt-5.6": {},
        "claude-sonnet-4-6": {}
      }
    }
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `nookmux` | 提供商 ID，模型以 `提供商ID/模型ID` 引用，例如 `nookmux/gpt-5.6` |
| `name` | 显示名称 |
| `env` | 提供凭据的环境变量名，启动 OpenCode 的环境里要有这个变量 |
| `package` | 运行时包，决定请求协议，见下表 |
| `settings.baseURL` | NookMux 站点地址 + `/v1`，三种协议都是这个地址 |
| `models` | 要使用的模型，键为模型 ID，与 NookMux 渠道中的模型名一致 |

`package` 的取值与实际请求的地址：

| `package` | 实际请求 |
| --- | --- |
| `@opencode/ai/providers/openai-compatible` | `<站点地址>/v1/chat/completions` |
| `@opencode/ai/providers/openai-compatible/responses` | `<站点地址>/v1/responses` |
| `@opencode/ai/providers/anthropic-compatible` | `<站点地址>/v1/messages` |

## 使用

1. 在 NookMux 控制台「密钥」页面创建令牌并复制完整密钥（以 API Key 前缀开头，默认 `sk-`）。
2. 导出环境变量：

   ```bash
   export NOOKMUX_API_KEY=sk-your-nookmux-token
   ```

3. 启动 OpenCode：

   ```bash
   cd /path/to/your/project
   opencode
   ```

4. 用 `/models` 选择 `NookMux` 下的模型。也可以在配置文件顶层加 `"model": "nookmux/gpt-5.6"`，把它设为默认模型。

## 常见问题

### 提示 No model is available for session

还没有可用的模型。确认配置文件里的提供商和模型无误、环境变量已导出，然后在 `/models` 里选择模型。

### 提示 Model unavailable: provider/model

提供商未激活，或模型 ID 不存在、被禁用。检查 `models` 里的键名是否与引用的模型 ID 一致。

### 401 / 无效令牌

确认启动 OpenCode 的那个终端里已导出 `env` 所列的环境变量，且值是以 API Key 前缀开头（默认 `sk-`）的完整 NookMux 令牌。
