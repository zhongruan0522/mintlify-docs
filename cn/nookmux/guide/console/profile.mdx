---
title: 个人资料
---

个人资料入口为 `/profile`，用于查看账号信息和配置通知方式；登录方式、Passkey、两步验证、访问令牌等安全相关功能位于「安全与访问」页（`/profile/security`）。两页均可从侧边栏 **个人** 分组或右上角头像菜单进入。界面语言在顶栏的语言切换器里切换，只对当前浏览器生效。

个人资料页主要区域：

- **账户概览**：查看头像、显示名、角色、用户名、邮箱、分组，以及当前余额、总用量、API 请求三项指标。
- **通知设置**：选择通知方式（`email`、`webhook`、`bark`、`gotify` 四选一），填写所选方式对应的字段，并设置额度告警阈值。点击页头「保存更改」后生效。
- **每日签到**：如果管理员启用签到，页面下方显示签到面板，可签到并查看月历、累计签到与奖励。

安全与访问页主要区域：

- **登录与认证**：更改密码；绑定站点已启用的邮箱、GitHub 或 LinuxDO 账号。每种方式一个面板，宽屏下一行三个，方式增多时自动换行。
- **Passkey 登录**：注册、重命名和移除 Passkey。
- **两步验证**：开启或关闭两步验证、重新生成恢复码。
- **访问令牌**：生成与管理 API Access Token。
- **删除账户**：位于页面底部，上方有高风险提示。

删除账户、生成 Access Token、绑定邮箱、开启两步验证等敏感操作会先弹出二次验证对话框（`POST /api/verify`），需以 2FA、Passkey 或密码完成一次安全验证。

更改密码、关闭两步验证、重新生成恢复码成功后，服务端会让当前账号的全部会话失效（包括其他浏览器和设备上的登录）：页面提示原因后回到登录页，重新登录后回到原来的页面；重新生成恢复码时会先展示新恢复码，关闭对话框后才回到登录页。

可用绑定方式和安全能力取决于管理员在 **系统设置 → 身份验证** 中启用的功能。
