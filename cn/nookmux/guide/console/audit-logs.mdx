---
title: 审计日志
description: 查看管理员对渠道、用户、令牌等系统资源的增删改记录，并在系统设置中控制记录哪些模块、是否记录 IP 与变更 diff。
---

审计日志入口为 `/audit-logs`，用于查看管理员对系统资源的增删改操作。

当前项目对渠道、用户、令牌、兑换码、模型、厂商、动态倍率、系统设置等资源的管理操作记录审计日志。

管理员可在 **系统设置 → 安全与限制 → 审计日志** 中控制：

- 是否启用审计日志。
- 哪些模块需要记录。
- 是否记录 IP。
- 是否记录变更 diff。

审计日志用于追溯管理操作，不等同于 API 使用日志。
