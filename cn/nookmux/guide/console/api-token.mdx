---
title: API 密钥
---

API 密钥页面入口为 `/keys`，用于创建、查看、编辑、重置和删除用户 API 密钥。

常见能力：

- 设置密钥名称、额度、过期时间和是否启用。
- 选择密钥可用分组与可调用模型。
- 配置 auto 分组、跨分组重试等调用策略（具体字段以当前页面为准）。
- 批量操作与复制调用配置。

## 密钥格式

API 密钥由站点密钥前缀和 48 位随机串组成。前缀默认为 `sk-`，管理员可在 系统设置 → 站点与品牌 → 系统信息 中自定义。「密钥」页面展示与复制的即为完整密钥，可直接填入应用使用。

管理员可通过 **系统设置 → 计费与支付 → 分组定价** 配置用户可选分组、自动分组和分组倍率。
