---
title: 控制台内容
---

旧文档中的“数据看板设置”现在位于 **系统设置 → 控制台内容**。

可配置分区：

- **仪表台配置**：数据看板行为的唯一配置入口——数据指标开关（配额数据、用户分析、排行榜、媒体转换统计）、写入层聚合粒度、面板开关、四个刷新间隔（配额数据/用户分析/排行榜/Uptime Kuma，单位秒）与数据限制（默认/最大查询时间范围、排行榜模型/供应商数量、用户分析 Top N）。原「数据仪表板」分区（数据导出开关、分钟级刷新间隔、默认时间粒度）已并入此处。
- **公告**：维护控制台公告。
- **API 地址**：维护首页/控制台展示的 API 地址快捷信息。
- **FAQ**：维护常见问题。
- **Uptime Kuma**：配置监控状态页分组。
- **使用日志字段**：配置管理员和普通用户在日志详情中可见的字段。

这些配置影响控制台展示与看板数据聚合，不直接改变 relay 调用行为。
