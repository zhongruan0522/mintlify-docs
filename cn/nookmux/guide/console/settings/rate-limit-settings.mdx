title: 安全与限制
description: 系统设置「安全与限制」中的模型请求速率限制与分组覆盖配置，该分组还包含敏感词、SSRF 防护和审计日志。
---

旧文档中的“速率限制设置”现在位于 **系统设置 → 安全与限制 → 速率限制**。

可配置项包括：

- 是否启用模型请求速率限制。
- 每个限制周期内最大请求数。
- 每个限制周期内最大成功请求数。
- 限制周期（分钟）。
- 基于用户分组的速率限制覆盖。

两项限额按用户分别计数。「每个限制周期内最大请求数」统计每一个放行的请求，包括失败的请求，填 `0` 表示不限制；「每个限制周期内最大成功请求数」只统计以小于 400 的状态码完成的请求，失败的请求不占用这项额度。被任一项限额拒绝的请求不计入任何一项。「限制周期（分钟）」填 `0` 时两项限额都不生效。

两项限额都按滑动窗口计算：从当前时刻往前一个限制周期内计入的请求数不超过设定值。超过任一项限额的请求返回 `429`，响应体说明命中的是哪一项限额，`Retry-After` 响应头给出建议等待的秒数（一个完整的限制周期）。

分组速率限制示例：

```json
{
  "default": [200, 100],
  "vip": [0, 1000]
}
```

同一分组下的具体含义以当前页面字段说明为准。安全与限制分组还包含敏感词、SSRF 防护和审计日志配置。
